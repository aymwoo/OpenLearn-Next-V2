# courseware-hub 使用帮助

## 概述

courseware-hub 是一个 AI 课件分发与成绩采集插件。你可以：

- 上传 AI 生成的交互式 HTML 课件
- 将课件发布到学生端
- 自动捕获课件中的学生成绩
- 成绩自动回传学期系统

---

## 一、上传课件

**从教师面板上传：**
1. 进入教师端 → 找到「课件管理」入口
2. 点击右上角 **+ 上传** 按钮
3. 拖拽或选择 `.html` 课件文件
4. 填写课件名称（默认取文件名）、描述、及格线
5. 点击 **确认上传**

系统会自动：
- 扫描课件安全风险（外部脚本、eval 等）
- 检测课件是否使用了 OpenLearn SDK 协议
- 未使用 SDK 的课件会自动注入成绩捕获脚本
- 低置信度情况会通过 AI 分析成绩采集方式

---

## 二、课件 SDK 协议

如果你在生成 HTML 课件时就告知 AI，可以直接嵌入 SDK 调用：

**最简单的方式（AI 生成课件时）：**

在课件 HTML 中，成绩计算完毕后：

```javascript
OpenLearn.submit(85, 100);           // 得分 85，满分 100
OpenLearn.submit(90, 100, {          // 带详细数据
  questions: [
    { id: 'q1', correct: true, answer: 'B' },
    { id: 'q2', correct: false, answer: 'C' },
  ]
});
```

**仅标记完成（无成绩）：**
```javascript
OpenLearn.complete();
```

**AI 生成课件的 Prompt 建议（附加在 Prompt 末尾）：**

```
在成绩计算完成的地方，调用 window.OpenLearn.submit(得分数值, 满分数值)
来提交成绩。不需要额外引入任何脚本，系统会自动注入。
```

---

## 三、配置成绩采集

如果课件使用了非标准格式，可在教师面板手动配置：

1. 选中课件 → **设置** Tab
2. 选择采集方式：

| 方式 | 说明 | 适用场景 |
|---|---|---|
| SDK 协议 | 课件调用 `OpenLearn.submit()` | 生成时已嵌入协议 |
| AI 自动检测 | 系统分析 DOM/Javascript | 课件有明确成绩显示 |
| CSS 选择器 | 手动指定 DOM 选择器 | 成绩渲染在页面上 |
| JS 变量 | 指定全局变量名 | 成绩存在变量中 |
| 学生手动录入 | 无自动采集 | 纯阅读型课件 |

3. 使用「预览 Tab 中的 **🔍 检查模式**」，悬停元素可复制 CSS 选择器

---

## 四、发布课件

- 课件上传后状态为「未发布」
- 点击 **发布课件** 后，学生端即可看到
- 再次点击可取消发布
- 上传新版本时，旧已发布版本自动归档

---

## 五、查看成绩

1. 选中课件 → **成绩** Tab
2. 查看：提交人数、平均分、最高分、最低分、及格率
3. 成绩明细表支持导出 CSV（点击 **导出 CSV** 按钮）
4. 成绩已自动回传到学期成绩系统

---

## 六、版本管理

- 每次上传同名课件时自动创建新版本
- 在详情页顶部可通过版本按钮切换查看历史版本
- 删除课件会清除所有版本和成绩数据

---

## 七、安全提示

上传课件时会自动扫描以下风险项：
- 外部脚本引用（非信任 CDN）
- eval() 动态执行
- document.cookie 访问
- 向外部 URL 发起网络请求
- localStorage 使用
- 动态代码执行（new Function）

扫描结果会在教师面板以黄色警告条显示，不阻止上传，仅供教师评估。

---

## 八、故障排查

| 问题 | 可能原因 | 解决 |
|---|---|---|
| 学生端看不到课件 | 课件未发布 | 教师面板 → 发布 |
| 成绩未自动采集 | 课件未使用 SDK 协议 | 检查设置 Tab 的采集配置 |
| 成绩为手动录入 | AI 分析置信度低 | 使用检查模式获取选择器手动配置 |
| 上传后提示安全警告 | 课件含外部脚本等 | 评估风险后决定是否使用 |

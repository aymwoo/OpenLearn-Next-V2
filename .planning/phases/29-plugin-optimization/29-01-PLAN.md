# Phase 29 Plan: 插件系统加固与优化

<objective>
本规划旨在优化 OpenLearnV2 的插件系统体验与安全边界：
1. 使 ZIP 插件包安装完成后，返回结果包含生成的 `pluginId` (UUIDv7)。
2. 支持使用 Manifest ID 别名对插件进行全生命周期管理（启用、停用、切换状态、卸载）。
3. 拦截并隔离 Worker-isolated 插件的 `IStorageService` 存取调用，限制在插件专属命名空间下。
4. 编写完备的自动化集成测试确保各项改动稳定无回归。
</objective>

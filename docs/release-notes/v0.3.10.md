# Release Notes v0.3.10

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.10** 是一次针对**运行期防版本漂移与插件生态兼容性治理（Plugin Ecosystem & SDK Suite Compatibility）**的关键补丁版本。本版本系统性地为 `npx openlearn-next doctor` 引入了对 **SDK 套件**、**核心内置插件平台引擎约束**以及**已安装/本地扩展插件兼容性**的全方位自动化体检，杜绝因版本漂移与插件依赖互锁引发的潜在系统异常。

---

## 核心新特性与优化

### 1. 命令行体检诊断升级 SDK Suite 综合检测 (`doctor`)
- **SDK 套件联动校验**：同步探测并比对 `@openlearn/plugin-sdk` 与 `@openlearn/plugin-test-kit` 的声明与解析版本；
- **依赖形态透明呈现**：在终端诊断表格中明确标注 `workspace 链接`、`精确 pin` 或 `^范围` 形态（如 `workspace 链接 → v3.6.0, test-kit v3.3.2`）；
- **版本漂移预警**：一旦发现实际解析版本与构建要求脱节，立即给出阻断性报错与修复指引。

### 2. 零依赖轻量级 SemVer 范围匹配引擎 (`satisfiesVersionRange`)
- **极致轻量**：保持 CLI 工具链零外部生产依赖的纯净特性，不引入额外的庞大第三方包；
- **全语法支持**：完整支持标准 npm 语义化版本范围规范，包括 `*`、`>=X.Y.Z`、`>X.Y.Z`、`<=X.Y.Z`、`<X.Y.Z`、`^X.Y.Z`、`~X.Y.Z` 以及多区间约束组合（如 `>=0.2.0 <1.0.0`）。

### 3. 官方内置核心插件平台引擎兼容性校验 (`Core Plugins`)
- **全量核心插件覆盖**：自动扫描 7 个官方内置系统插件：
  1. `builtin`（系统基础功能）
  2. `vfs`（虚拟文件系统）
  3. `process`（进程管理）
  4. `management`（LMS 管理服务）
  5. `ai-planner`（AI 教学规划器）
  6. `ai-submit-injector`（AI 作业注入器）
  7. `assignment-eval`（智能作业批改）
- **强断言引擎约束**：严格校验内置插件的 `engines.openlearn`（当前约束 `>=0.2.5`）是否 100% 被平台版本满足，杜绝平台更新带来的核心插件互锁。

### 4. 扩展插件版本与平台兼容性自动体检 (`Installed Plugins`)
- **数据库与文件系统双源探针**：连接 SQLite 只读读取 `plugins` 数据表，并同步扫描本地 `plugins/` 目录；
- **清单有效性校验**：检测损坏的 `manifest.json` 与非规范的版本号格式；
- **动态引擎约束核验**：针对已安装扩展插件声明的 `engines.openlearn` 进行平台兼容性判定，若插件要求未来平台或旧平台，自动在终端给出预警清单与处置指引。

## 升级与自检指引

```bash
# 使用最新补丁版本运行环境体检
npx openlearn-next@latest doctor

# 一键自愈（清理旧版 NPX 缓存、创建存储目录）
npx openlearn-next@latest doctor --fix
```

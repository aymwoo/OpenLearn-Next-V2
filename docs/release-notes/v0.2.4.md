# Release Notes v0.2.4

**发布日期**: 2026年8月29日

## 主要更新

### 1. 前端架构解耦（`App.tsx` 瘦身）
- **根组件瘦身**: `src/App.tsx` 由 **3,974 行缩减至 1,722 行**（-2,252 行，-56.7%），由巨型根组件转型为路由与上下文协调器。
- **领域 Hook 抽取**: 将计算机实验室排课/座位/考勤（`useLabAndSchedule`）、成绩加权导出（`useGradeExport`）、课程时间轴（`useLessonTimeline`）、学生通知（`useStudentNotifications`）、课程筛选（`useLessonFiltering`）、插件管理（`usePluginManagement`）、课程向导（`useCourseWizard`）、AI 出题（`useQuizGenerator`）与批量操作（`useClassBatchOperations`）逐一拆分为独立 Hook。
- **纯服务模块**: 拆分 `bulkImportService`（CSV/JSON 导入解析与模板下载）与 `gradeReportService`（成绩报告）。
- **`AppModals` 适配器模式**: 模态框 props 重构为结构化 Hook 束适配器，消除大量顶层 prop 透传。

### 2. 冗余状态与阴影修复
- 清理 `App.tsx` 中的重复状态声明与重复数据请求。
- 修复单班级与多班级 PDF 报告生成的状态冲突。

## 版本说明

- 平台 `openlearn-next` 升至 **0.2.4**。
- `@openlearn/plugin-sdk` 保持 `3.5.0`。

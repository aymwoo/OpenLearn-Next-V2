# Release Notes v0.7.16

**发布日期**: 2026-11-15

v0.7.16 是功能增强与稳定性补丁版本，带来登录页学生自助查询学号、社区插件更新提醒与快照回滚、运行时策略管理化配置、第三方声明式主题、统一文件存储与多项课堂/无障碍体验修复。

## Features

- **登录页学生端自助查询学号（Issue #538, PR #539）**：
  - 新增数据库迁移 `056_public_student_lookup.sql`，支持管理员在站点设置开启/关闭公开学号查询并配备限流防护；
  - 学生端登录页支持按姓名检索并一键回填学号。
- **社区插件更新提醒与快照回滚（PR #537, #525, #523）**：
  - 社区市场支持检测版本更新提醒并在更新前自动留存快照、支持弹窗一键回滚；
  - 展示插件发布时间、ZIP 体积与实时 Gitee Star 数，并简化社区插件直装门槛。
- **后台运行时策略与社区安装开关（PR #528, #521, #514）**：
  - 新增迁移 `051`–`053`，将社区注册表地址、社区安装开关、课件遥测、HTTP 访问日志与未签名插件策略纳入管理后台可视化配置（界面显式配置优先于环境变量）。
- **AI 配置与可扩展内核 AI 助手 Persona（PR #512, #507）**：
  - 管理后台「AI 配置」统一入口与 AI 助教角色全生命周期治理（迁移 `049`、`050`），支持插件通过 `ai:persona` 能力扩展或替换助手角色。
- **统一文件持久化与三插槽扩展架构（Issue #504, PR #505）**：
  - 新增迁移 `048_file_storage_extension.sql`、`GET /api/files/:assetId` 安全读取网关及 `LayoutPolicy` / `StorageBackend` / `FileProcessor` 三插槽扩展。
- **第三方声明式主题系统（Issue #484, PR #500）**：
  - 新增迁移 `047_third_party_theme_system.sql`，支持声明式主题 `.zip` 包安全沙盒校验、多账号独立主题覆盖与插件 iframe 主题同步。
- **互动白板扩展槽与现代 Web 体验增强（PR #517）**：
  - 白板工具栏/页面栏/属性栏新增上下文插件插槽与沙盒视图渲染能力。

## Fixes

- **登录与导览体验修复（PR #536, #534, #483）**：登录页版本徽标实时读取 `/health`、新手引导支持全步骤跳过且按账号持久化状态、补全自动填充与中文输入法 Enter 防误触。
- **课堂协同与轮询稳定性修复（PR #535, #520, #485）**：完成课堂实时工具栏与协作白板接线（迁移 `055`）、消除 403 轮询刷屏与字体 CSP 报错、补全 `favicon` 并消除白板画布滚动条闪烁。
- **弹窗、表格与无障碍迁移（PR #499, #495, #527, #531, #491, #490）**：核心弹窗全面迁移至原生 `<dialog>` + `showModal()` 并修复异步关闭竞态；补全语义地标、`PasswordInput` 与响应式可访问表格。
- **安全与宿主可靠性修复（PR #511, #498, #497, #496, #480）**：统一 AI Provider URL/SSRF 校验策略源、修复局域网 HTTP 部署下 `upgrade-insecure-requests` 误升级、sql-guard 放行合法 `ON CONFLICT DO UPDATE SET` 与全仓审计问题收敛。

## Docs & Ops

- 同步升级 Node 运行时基线至 Node 24（支持范围仍涵盖 `20.x / 22.x / 24.x`），强化 Gitee 镜像同步可观测性与严格校验模式（PR #516, #519）。
- 完整同步迁移台账 `046`–`056`、数据表清单、HTTP 端点总览与 Agent 事实契约。

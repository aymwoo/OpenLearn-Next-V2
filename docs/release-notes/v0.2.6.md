# Release Notes v0.2.6

**发布日期**: 2026年8月30日

## 主要更新

### 1. 核心安全体系全面加固 (Security Hardening)
- **能力系统最小特权原则**：移除 `packages/core/capability-system/index.ts` 中 `'user-frontend': ['*:*:*']` 的通配符特权，改为按角色精准授权；未登录匿名访客分配 `anonymous: []` 零特权。
- **Worker 线程沙箱防逃逸**：在 `packages/core/worker-runtime/worker-manager.ts` 的 `ctx.require` 中注入 Node.js 敏感模块黑名单（禁止加载 `child_process`, `fs`, `net`, `http`, `os`, `vm`, `cluster`, `worker_threads` 等）。
- **LMS Bridge 跨窗口来源比对**：在 `src/services/lms-bridge.ts` 中校验 `event.source` 是否属于当前 DOM 中的合法 `iframe.contentWindow`，彻底阻断跨窗口消息伪造。
- **AI 提供商连通性 SSRF 防护**：在 `server/routes/plugins.ts` 中引入 `isSafeExternalUrl` 校验，拦截针对本地回环与私有局域网网段的恶意探测。
- **系统指令总线鉴权**：在 `server/routes/os.ts` 中对 `POST /api/commands` 路由挂载 `requireAuth()` 中间件。

### 2. TypeScript 编译与类型契约彻底修复 (72 Errors -> 0)
- **消除前端主壳 TDZ 隐患**：重构 `src/App.tsx` 中的 Hook 拓扑声明顺序，引入 `chatLogUpdaterRef` 解决延迟绑定，使得 `useCourseWizard`、`usePluginManagement`、`useAgentChat` 依赖完备就绪。
- **对齐组件契约与回调签名**：
  - `src/features/teacher/Dashboard.tsx`：适配 `scoreOverrides` 状态更新器与 `QuickActionsMenu` 异步回调。
  - `src/features/teacher/PluginView.tsx`：引入严格 `Language` 与 Tab 联合类型。
  - `src/features/teacher/classes/ClassStudentsPanel.tsx`：支持函数式更新器 `(prev => ...)`。
  - `src/hooks/useGradeExport.ts`：校准 `exportAllClassesCombinedCSV` 参数传递结构。
  - `src/components/PluginSettingsModal.tsx`：严格声明 `ConfigProperty` 类型断言。
  - `src/features/ai-classroom-context/` & `classroom-runtime/`：修复多态值类型、只读数组解构以及 `EventBus.publish` 的 `metadata: {}` 字段。
- **对齐核心包与 Zod v4 契约**：
  - `packages/core/esm-loader/manifest-schema.ts`：适配 Zod v4 双参 `z.record(z.string(), z.unknown())`。
  - `packages/plugins/__tests__/*.test.ts`：抽象类 `new EsmLoader()` 替换为实体类 `new NodeEsmLoader()`。
  - `server/routes/grading.ts`：`kernelContainer.registry` 修复为 `kernelContainer.serviceRegistry`。
  - `packages/core/configuration/PlatformConfiguration.ts`：修复 `ConfigurationContext` 模块导入并放开动态扩展属性的可变性。

### 3. 数据库 9 处高频核心业务索引优化
- 在 `packages/core/db/index.ts` 中新增 9 个针对性复合与二级索引：
  - `idx_whiteboard_lesson`（白板元素课时关联）
  - `idx_class_students_class` & `idx_class_students_student`（班级学生多对多双向查询）
  - `idx_schedules_class_date`（班级日常排课与考勤日程）
  - `idx_courseware_attempt_cw_st`（课件答题作答记录）
  - `idx_submission_result_attempt`（作业提交批改结果）
  - `idx_events_type_time`（事件审计时序检索）
  - `idx_assignments_class`（班级作业发布）
  - `idx_attendance_schedule`（排课签到状态）

### 4. 插件生态与扩展点特性
- **插件锚点扩展槽（Anchor Slots）**：支持通过 `anchor:*` 槽位与 `placement="before|after"` 在白板工具栏、控制面板等原生按钮前后动态插入插件按钮。
- **扩展点稳定排序**：`plugin-host-store.getExtensions` 统一按 `position` 升序稳定返回。

# Release Notes v0.4.1

**发布日期**: 2026年9月27日

OpenLearn V2 **v0.4.1** 是 v0.4.0 的**插件生态扩展补丁 (Plugin Ecosystem Extension Patch)**，落地 P1 扩展插槽：课件播放器工具栏与浮层 HUD、作业题型渲染器扩展注册表。

---

## 一、课件播放器扩展插槽

- **`courseware.viewer.toolbar`**：播放器顶栏标题区与控制按钮之间注入教辅工具（草稿本浮窗 / 截图批注 / 双语即时字幕 / 课件随堂笔记等）。
- **`courseware.viewer.overlay`**：课件 iframe 上方叠加 HUD 容器（全班弹幕 / 防作弊水印 / 抢答悬浮球等）。容器为 `pointer-events-none`，插件子元素自行开启交互，不遮挡课件本体操作。

## 二、作业题型渲染器扩展（assignment.question.renderer）

新增 `AssignmentQuestionRendererRegistry`（`src/features/teacher/assignment-question-registry.ts`）：

- 第三方插件经 `ctx.ui.registerAssignmentQuestionRenderer` 注册学科专属题型（在线代码沙箱运行题 / 口语发音评分题 / 动态几何尺规作图题）。
- 匹配规则：作业 `content` 以 `{"quizType":"<quizType>"` 开头即命中，整面板交给插件渲染（`render` / `validate` / `buildSubmission` 四钩子）。
- 内置 `mcq_learning_objectives` 题型与纯 Markdown 内容保持宿主原有渲染路径，行为无任何变化。
- 插件卸载时按 `pluginId` 所有权清理（`clearOwned`），防止插件互删。
- `StudentAssignmentQuestionPanel` 新增可选 prop `setQuizStudentAnswers`，插件题型载荷经父级提交链路写入。

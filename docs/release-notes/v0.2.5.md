# Release Notes v0.2.5

**发布日期**: 2026年8月29日

## 主要更新

### 1. Vite 细粒度分包与入口体积锐减
- **入口包缩减 90.1%**: 入口 `index.js` 由 **2,181.47 kB（2.18 MB）降至 216.43 kB（gzip 66.69 kB）**。
- **模块化 `manualChunks`**: 在 `vite.config.ts` 中将第三方依赖拆分为分类 vendor chunk（`vendor-react`、`vendor-charts`、`vendor-pdf`、`vendor-konva`、`vendor-reveal`、`vendor-pptx`、`vendor-icons`、`vendor-motion`、`vendor-content`、`vendor-utils`）。

### 2. 系统级异步组件懒加载（`React.lazy` & `Suspense`）
- **`AppModals`**: 将 13+ 模态框（课程向导、AI 出题、导入、批量选择、导出权重、云盘、资源库、学生预览、过程日志、帮助引导等）改为按需异步加载。
- **`AppShell`**: 通过 `React.lazy` 解耦 `TeacherView` 与 `StudentView`，学生会话不再加载教师端代码。
- **`TeacherView`**: 非首页子视图（班级、课表、机房、管理目录、帮助、插件、直播课堂）懒加载。
- **`StudentView`**: `StudentLessonView` 与 `StudentAssignmentView` 懒加载。

### 3. 异步单测兼容
- 更新 `TeacherView`、`StudentView`、`AppShell` 单测以支持异步 DOM 查询（`await screen.findByText`）与 `Suspense` 水合。
- 测试夹具补充 jsDOM `ResizeObserver` mock 与 mock socket 实例。

## 版本说明

- 平台 `openlearn-next` 升至 **0.2.5**。
- `@openlearn/plugin-sdk` 保持 `3.5.0`。

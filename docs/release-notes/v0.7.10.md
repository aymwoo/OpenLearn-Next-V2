# Release Notes v0.7.10

**发布日期**: 2026-11-02

v0.7.10 升级插件 SDK 3.8.0，并显著降低首次安装与插件开发的摩擦。

## Features

- **`@openlearn/plugin-sdk` 3.8.0**：能力字符串清单与校验函数、`IActionRegistryService` 只读查询、受管名册 `IClassRosterService` / `ctx.services.roster`。
- **插件命令自检（Issue #369）**：激活后自动列出「有 handler 但缺 ActionDescriptor」的命令。
- **能力清单单一来源（Issue #368）**：`capability/catalog.ts` 统一 `CAP`，加载期校验未知能力。
- **初始口令默认等于用户名**：`admin/admin`、`teacher/teacher`，首次登录强制改密；可用 `OPENLEARN_SEED_PASSWORD_MODE=random` 恢复旧行为。
- **inline 插件 SQL-Guard（Issue #367）**：`OPENLEARN_SQL_GUARD_ALL_MODES` 开关下与 worker 同口径。
- **受管名册读取服务（Issue #366）**：插件经 `ctx.services.roster` 读取班级/学生最小字段。

## Fixes

- **白板挂件双端 id 缺失**（Issue #370）：缺一端时自动补齐并告警；两端都缺则拒绝写入，前端显示错误态而非永久加载。

## Docs

- 数据库 API、插件教程与初始口令说明同步更新。

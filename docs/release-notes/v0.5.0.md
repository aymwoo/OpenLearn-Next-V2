# Release Notes v0.5.0

**发布日期**: 2026年10月2日

OpenLearn V2 **v0.5.0** 是平台里程碑式的大版本升级（**System Robustness & Architecture Decoupling Milestone**）。本版本完成了平台核心安全体系重构、数据持久层全面事务化、前端巨石架构极简化蜕变以及插件体系全生命周期闭环治理。

---

## 一、前端架构全面解耦与极简入口蜕变（Architecture Decoupling）

1. **App.tsx 极简入口达成（1764 行 → 130 行）**：
   - 抽取编排引擎 `useAppComposer`，解耦 10 个业务 Hook、Socket 信道连接与长轮询调度；
   - 抽取 `ClassroomOverlays` 与 `ImpersonationBanner` 浮层组件；
   - `AppHeader` 升级为 0 props 自动根据 Context 挂载与分发。
2. **状态层彻底下沉（AppDataContext 体系）**：
   - `RightSidebar`（25 props → 0）、`AppModals`（70 props → 0）与全部 TeacherView 子模块（10 个业务 Tab）全面迁移经 Context 取数；
   - 彻底消除逐层 Props 传递（Prop Drilling）样板代码，提升重渲染性能。
3. **LiveClassroomView 巨石解耦**：
   - 抽取 `LiveSubmissionsPanel`（360+ 行），独立承载学生课件提交记录、自动录入成绩规则与过滤逻辑；
   - 抽取 `ClassroomToolbarQuickActions` 工具栏，统一 7 个流程扩展按钮与倒计时部件。

---

## 二、平台安全与认证体系全面加固（Security & Protection）

1. **业务 ID 强随机安全化**：
   - 全面淘汰 `Math.random().toString(36)` 弱随机数生成器，统一升级为 `crypto.randomUUID()`、`uuidv7()` 与 `crypto.randomBytes`；
   - 彻底杜绝全局事件 ID、排课 ID 与调度 ID 的猜测与遍历漏洞。
2. **统一错误响应脱敏（SEC-ERR）**：
   - 收敛服务端遗留裸写 500 响应，接入统一 `sendSafeError()`；
   - 生产环境统一脱敏屏蔽底层 SQL 与堆栈，开发环境保留完整调试信息。
3. **AI 关键端点限流防护（Rate Limiting）**：
   - 为 `/api/agent/chat` 与 `/api/ai-providers/test` 挂载限流中间件，防止大模型供应商额度被并发滥用。

---

## 三、运行时内存与微前端沙箱可靠性（Runtime Reliability）

1. **课时生命周期与内存防爆**：
   - `shared-state` 引入 FIFO 500 容量上限与防溢出淘汰机制，联动课时删除生命周期彻底杜绝驻留内存泄漏。
2. **插件生命周期与 EventBus 退订闭环**：
   - 修复插件代理中原始函数引用无法命中的缺陷，引入 WeakMap 映射，保障插件主动 `unsubscribe` 与卸载清理时 100% 移除监听器。
3. **沙箱 Bridge 跨窗口通信防爆**：
   - 引入 512KB 单包尺寸校验与循环引用拦截，丢弃超大异常 payload，保护宿主渲染线程。

---

## 四、升级指南与兼容性说明

- **内核与插件兼容性**：核心接口保持完全向后兼容，所有内置插件与生态插件平滑升级。
- **数据库兼容性**：无需执行破坏性迁移，历史 SQLite 数据库自适应平滑启动。

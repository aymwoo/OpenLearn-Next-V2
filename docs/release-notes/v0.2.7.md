# Release Notes v0.2.7

**发布日期**: 2026年8月31日

## 主要更新

### 1. 严格无同源沙箱隔离改造 (Strict Sandboxing)
- **移除 `allow-same-origin`**：全面清理 `InteractiveWhiteboard.tsx`、`InteractiveCoursewareViewer.tsx` 以及 `FullscreenRendererRegistry.tsx` 中 iframe 的 `allow-same-origin` 声明。
- **统一规范**：所有互动课件与白板扩展组件统一运行在 `sandbox="allow-scripts allow-forms allow-downloads"` 的严格沙箱中，彻底消除潜在 DOM 同源提权风险，全量跨窗口数据交互均通过 LMS Bridge Proxy SDK 安全代理。

### 2. 数据库外键级联约束强制开启 (Database Integrity)
- **启用 `PRAGMA foreign_keys = ON;`**：在 `packages/core/db/index.ts` 中初始化连接配置时开启外键约束，在 SQLite 引擎层实现严格的实体完整性检查，杜绝班级-学生、排课-考勤、课件-作答等表之间的孤儿关联数据。

### 3. 工程化与代码规范调优 (Tooling & Linting)
- **ESLint TS 规则对齐**：在 `eslint.config.js` 中显式关闭针对 TypeScript 文件的 `no-undef` 规则，将类型检查完全交由 `tsc` 裁定，消除了数千条纯 JS 误报。

## 版本说明

- 平台 `openlearn-next` 升至 **0.2.7**。
- `@openlearn/plugin-sdk` 保持 `3.5.0`。
- 全量自动化测试套件 **169 / 169 (941 测试用例) 100% 通过**。

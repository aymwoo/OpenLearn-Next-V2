# Release Notes v0.7.17

**发布日期**: 2026-11-15

v0.7.17 是补丁发布版本，合入并发布社区插件安装与刷新加载体验增强及前端工程规范文档更新（PR #541）。本版本不包含破坏性变更与数据库结构迁移。

## Features

- **社区插件安装与刷新加载反馈优化（PR #541）**：
  - 在社区插件市场（`PluginCommunityPanel.tsx`、`PluginCenter.tsx`）新增安装加载状态指示、进度动画（`@keyframes indeterminate-progress`、`progress.community-loading-progress` 及 `prefers-reduced-motion` 适配）及刷新列表加载横幅；
  - 完善社区注册表刷新与插件安装链路（`server/routes/plugins.ts`、`server/services/community-registry.ts`、`packages/core/plugin-host/install.ts`）与对应单测。

## Docs

- **前端 Web 标准开发约束（PR #541）**：在 `AGENTS.md` 与 `CLAUDE.md` 补充客户端/界面开发优先使用 `modern-web-guidance` 的协作要求。

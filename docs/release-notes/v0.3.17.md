# Release Notes v0.3.17

**发布日期**: 2026年9月19日

OpenLearn V2 **v0.3.17** 是一个**功能扩展与课堂管控能力增强版本 (Feature Extension & Classroom Control Release)**。本版本开放了备课画板的插件扩展插槽，补齐了互动课堂的独立标签页学生端与全局错误诊断中心，引入了「全班专注锁定」的只读跟随模式与教师端组件最大化视图同步，并修复了一个会导致教师端课程编辑器完全不可用的无限重渲染缺陷。

---

## 一、插件生态与备课画板扩展

### 1. 课程设计备课画板组件插件扩展插槽 (`paletteItemRegistry`)

- **画板组件注册表**：基于 Zustand Vanilla Store 构建响应式注册单例，开放 `register`、`unregister`、`unregisterPlugin(pluginId)` 与 `usePluginPaletteItems` 响应式 Hook；第三方插件可向备课画板贡献专属教学组件（学科仿真实验、3D 分子模型、乐谱、编程评测沙箱等）。
- **插件上下文契约扩展**：`FrontendPluginContext.ui` 新增 `ctx.ui.registerPaletteItem(config)` 与 `ctx.ui.unregisterPaletteItem(type)`。
- **备课组件库无缝聚合**：`LessonPalette` 动态聚合并实时响应插件组件，新增「插件扩展」分组，自动享受中英文检索、拼音首字母匹配、分类折叠、收藏置顶与最近使用机制。
- **声明式配置弹窗**：`PaletteCardEditModal` 支持插件声明 `editFields`（`input`、`textarea`、`select`、`options` 等），教师点击卡片时自动唤起配置表单并支持动态/异步加载选项。
- **标准教学卡片容器与属性侧边栏回退**：白板自动为插件组件提供统一的标题栏拖拽手柄、缩放 handles、最小化折叠、全屏放大与删除控制；未注册专属 `propertyEditor` 时，右侧属性检查器基于 `editFields` 自动生成通用配置表单。
- **生命周期自动回收**：`unregisterPluginResources(pluginId)` 与插件停用/卸载联动，自动清理插件注册的画板组件，防止内存泄漏与残留脏配置。
- **SDK 类型同步**：`@openlearn/plugin-sdk` 导出 `PaletteItemConfig`、`PaletteEditField`、`PaletteSelectOption`、`PaletteItemComponentProps`。

### 2. 互动课堂独立标签页学生端与多端实时同步

- **独立浏览器标签页学生端**：互动课堂的学生视角可从页面内弹窗/抽屉改造为弹出独立的浏览器标签页，便于教师在多屏或分屏环境下双端实时对照教学效果。
- **双向广播联动通道 (`ClassroomSyncChannel`)**：基于 `BroadcastChannel` 与 Socket.IO 构建低延迟双向联动通道，教师端的页面切换、白板标注涂写、组件缩放移动与课件交互实时同步至独立学生端 tab。
- **多端状态感知**：支持主动心跳检测、掉线重连感知与独立窗口关闭状态同步。

### 3. 全局系统错误诊断中心

- **全局未捕获异常监听 (`useGlobalErrorCapture`)**：统一捕获 `window.onerror`、`unhandledrejection` 以及 React 渲染 ErrorBoundary 异常。
- **系统级错误诊断模态框 (`SystemErrorCenterModal`)**：通过全局 Toast 提供快速入口，智能提取错误分类、发生时间、课程/班级上下文以及格式化调用堆栈。
- **智能排查建议与一键复制**：针对常见网络中断、插件执行异常、CSP 拦截提供分类排查建议，并支持一键复制带 Markdown 格式的诊断报告。

## 二、互动课堂课堂管控能力增强

### 4. 全班专注锁定：只读跟随模式

教师一键「全班专注锁定」后，学生端进入严格的只读跟随模式：

- **视图切换唯一收口 (`setStudentViewStatus`)**：锁定期间学生端只放行 `lesson` 视图，其余跳转（系统总览、作业工作区、通知直达等）统一拦截并弹出提示；修复了此前「只禁用了返回学习面板按钮」导致学生仍可自由切换页面的问题。
- **顶部导航与品牌区拦截**：`AppHeader` 的系统总览按钮与站点 Logo 在锁定期间不再跳转，改显锁图标与提示文案。
- **标签页与教学环节锁定**：白板/互动课件/作业标签页与时间线环节切换在锁定期间禁用并提示，仅允许跟随教师端广播。
- **白板只读模式 (`InteractiveWhiteboard readOnly`)**：隐藏顶部工具栏与页面栏，画布 `pointer-events: none` 禁止绘制，禁用右键菜单、浮动删除胶囊与元素删除，同时**保留**测验、随机点名、演示文稿等插件组件本体的交互能力。
- **底层写入兜底**：`handleElementDelete` / `handleClearBoard` / `handleResetBoard` 与 `onElementDelete` / `onClearBoard` 在只读模式下直接拒绝，防止绕过 UI 触发白板清空。
- **强制跟随教师步调**：锁定期间自动开启并禁用「跟随教师步调」开关，同时确保学生落在课节视图，不会被困在其他页面。

### 5. 教师端组件最大化视图同步至学生端

教师在互动课堂中最大化某个白板组件时，全班学生的屏幕会同步进入该组件的全屏视图：

- **班级房间投递 (`class-<classId>`)**：服务端在 `register-student` 时按 `class_students` 将学生 socket 加入其所属班级房间，教师端同时投递到课节房间与班级房间。因此学生无论处于课节白板、互动课件、作业标签页、**作业工作区**（此前会 `leave-lesson`）还是**从学习面板直接打开作业**，都能收到同步。
- **远程视图状态中心 (`whiteboardViewStore`)**：最大化状态提升至独立 Zustand Store，避免学生切到「互动课件/作业」标签页导致白板卸载后同步视图丢失。
- **强制切回白板并全屏**：学生收到广播后强制切换到交互式白板标签页并进入全屏遮罩；学生在自学其他课节或停留在学习面板时不会被打断。
- **原路返回**：中断前记录学生的视图状态、标签页、课节与被打开的作业，教师退出最大化后恢复原位（同一次中断只捕获一次，反复最大化不会覆盖最初位置）；被拉出作业工作区期间会暂存并清空作业上下文，避免 `useAppPolling` 同时拉取两个房间的 `elements` 互相覆盖。
- **不可本地退出**：教师同步视图隐藏关闭按钮、ESC 不生效，插件自定义全屏渲染器拿到的 `onClose` 亦为空操作。
- **防卡死收敛**：教师端离开白板（切中控台 Tab / 换课节 / 卸载）或被最大化元素被删除时广播 `elementId: null`，学生端重连时同样恢复被中断的视图，避免学生被永久困在不可退出的全屏中。

### 6. 白板与备课互动课件属性模型统一

备课画板与互动上课白板中「互动网络课件」属性面板重构，统一使用 `coursewareUuid` 资产标识，移除冗余的 `resourceId` 字段；统一关联课件列表选择器与本地课件压缩包文件上传流程，规避参数歧义。

## 三、缺陷修复与安全加固

### 7. 课程编辑器无限重渲染导致崩溃（严重）

- **缺陷现象**：渲染教师端「课程编辑器」时抛出 `Maximum update depth exceeded`，伴随 React 警告 `The result of getSnapshot should be cached to avoid an infinite loop`，该 Tab 完全不可用。
- **根本原因**：`usePluginPaletteItems` 的选择器体 `Array.from(state.items.values()).map(...)` 每次 `getSnapshot()` 都会分配一个新数组，而 `useStore` 底层是 `useSyncExternalStore`（用 `Object.is` 比较连续快照），于是 React 永远判定快照已变化、每次提交都强制重渲染，直至触发嵌套更新上限。只要渲染到备课组件库（`LessonPalette`）就会复现，与是否选中课节无关。
- **修复方式**：使用 `useShallow`（`zustand/react/shallow`）包裹选择器，将不稳定数组收敛为引用稳定的结果。
- **影响范围扫描**：逐一审查了全部 store 选择器，其余均返回单一字段（引用天然稳定），并确认仓库内不存在手写 `useSyncExternalStore`，此类缺陷全仓仅此一处。
- **回归测试**：新增 `palette-item-registry.test.tsx`，以「单组件 + 单 Hook + 空 Store、零写入」的最小场景锁定重渲染次数。

### 8. CSP 内容安全策略内联脚本告警修复

规范内联事件处理器编写，消除浏览器控制台中关于 `script-src-attr 'none'` 的 Content Security Policy 告警。

## 四、升级说明

本版本无破坏性变更，可直接覆盖升级。

- **平台**：`openlearn-next` `0.3.16` → `0.3.17`

- **插件测试工具**：`@openlearn/plugin-test-kit` `3.3.2` → `3.3.3`

已安装插件的 `engines.openlearn` 兼容性校验保持不变，无需插件侧改动即可升级。

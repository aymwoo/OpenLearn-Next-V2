# Release Notes v0.2.0

**发布日期**: 2026年7月28日

## 主要更新

### 1. 平台类型系统与排错优化
- 彻底排查并修复 `tsconfig` 中的排他配置，消除隐蔽类型错误。
- 升级 `@openlearn/plugin-sdk` 至 `3.5.0`，对 `PluginContext.resolve<T>` 的 Token 泛型推导进行了精准收紧。

### 2. 服务端单体解耦 (Server Monolith Decomposition)
- **`server/realtime-bridge.ts`**: 抽离 EventBus 到 Socket.IO 的实时同步转发模块（作业批改通知、白板实时同步、聚光灯同步）。
- **`server/ai-agent.ts`**: 抽离 AI 聊天编排、System Prompt 组装与 OpenAI/Gemini 函数调用拆解。
- **`server/presence.ts`**: 抽离在线感知与房间加入/退出网络生命周期逻辑。
- **`server/bootstrap-db.ts`**: 抽离 boot-time 数据库种子、表迁移与 Session 清理。

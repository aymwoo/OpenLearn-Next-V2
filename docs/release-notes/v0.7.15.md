# Release Notes v0.7.15

**发布日期**: 2026-11-12

v0.7.15 是平台高并发性能优化、超大文件架构解耦与 TypeScript 类型治理补丁版本。本版本不包含破坏性 API 变更与数据库结构迁移。

## Features

- **SQLite 高并发容量验证压测套件（`scripts/stress/`，Issue #407）**：
  - 核心压测引擎 (`sqlite-load.mjs`)：多 Worker 线程真实连接竞争模型与单进程异步模型对照；
  - 全链路 HTTP 业务压测 (`http-load.mjs`)：覆盖学生登录、课件拉取、互动晴雨表、作业提交与慢查聚合；
  - 一键调度主脚本 (`run-all.mjs`) 与快捷命令（`pnpm stress`、`pnpm stress:db`、`pnpm stress:http`）。

## Refactor / Performance

- **超大文件架构解耦与渐进式拆离（Issue #434）**：
  - **白板大文件解耦**：抽离 `useQuizIngest`、`useWhiteboardPages`、`useWhiteboardDrop` 三大独立 Hook，单文件净减 483 行；
  - **课堂大视图解耦**：抽离 `ClassroomTimelineSidebar.tsx` 大纲侧边栏组件，单文件净减 360 行；
  - **服务端主路由解耦**：外移 `classroom-teaching-modes.ts` 与 `classroom-preset-polls.ts` 两个子路由，单文件净减 339 行（降至 2870 行）。
- **宽表查询收敛与分页限制（Issue #435）**：
  - 高频宽表查询由无边界 `SELECT *` 收敛为显式字段清单；
  - 为所有无上限列表查询增加默认 `LIMIT 200` / `LIMIT 50` 约束。
- **全仓 any 深度治理与告警预算收紧（Issue #433）**：
  - 治理服务端路由与核心边界类型定义，沉淀统一安全 Session 提取与 DB Row 强类型接口；
  - ESLint 告警从 6085 降至 5839 条（累计净降 246 条），CI 预算基线同步锁紧。
- **高并发读写性能与会话治理（Issue #409, #410, #411, #427）**：
  - 通用 TTL 只读内存缓存引擎 (`server/utils/ttl-cache.ts`)；
  - 只读连接池自适应扩容与 `general` / `heavy` 双泳道借用隔离；
  - 会话活跃度与晴雨表信号微批量落库引擎；
  - 课堂会话只读查询收敛至 `ClassroomSessionService`。

## Fixes

- **插件指南发布路径（Issue #412）**：`docs_plugin_guide.md` 纳入发布清单，按包内路径解析。
- **管理端日志路径（Issue #413）**：统一使用 `log-paths.ts`，修复容器部署下日志页为空的问题。
- **作答事件规范化（Issue #414）**：平台规范化补发 `quiz.answered` 事件，消除弃用告警。

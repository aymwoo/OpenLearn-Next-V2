# Release Notes v0.3.6

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.6** 是聚焦于**防版本漂移质量加固（Anti-Drift Architecture & Automated Test Gate）**的平台治理版本。本版本彻底消除了内核导出层的重复字面量定义，构建了 6 维自动化版本一致性拦截门禁，并实现了 Sphinx 文档系统与根版本号的动态绑定。

---

## 主要更新

### 1. 内核导出版本强收敛
- 将 `packages/core/bootstrap/types/index.ts` 中的 `PLATFORM_VERSION` 改为直接从单一真理源 `packages/core/version.ts` 导入，彻底消除内核内部双重硬编码字面量的潜在脱节风险。

### 2. 全自动防版本漂移质量门禁 (Quality Gate)
- 新增专用自动化测试套件 `packages/core/__tests__/version-consistency.test.ts`，设立 6 重自动化强断言：
  1. 根目录 `package.json.version` 强等于 `PLATFORM_VERSION`；
  2. `OPENLEARN_VERSION` 别名强等于 `PLATFORM_VERSION`；
  3. `bootstrap/types` 导出的平台版本强等于核心版本；
  4. `PlatformBuilder` 构建元数据与环境版本强等于核心版本；
  5. 全量 7 个核心内置插件的 `engines.openlearn` 约束能被平台当前版本 100% 满足；
  6. `docs/conf.py` 动态或静态严格与 `package.json` 对齐。
- 任何发版若漏改任一处或引发插件互锁，`pnpm test` 会在 1 秒内阻断发布流程并给出精准错误指引。

### 3. Sphinx 文档系统动态版本绑定
- 改造 `docs/conf.py`，改用 Python 原生动态读取根目录 `package.json` 的版本号，保证 Sphinx 文档中心版本与平台主版本始终 100% 步调一致。

### 4. SDK 依赖与发版脚本加固
- 升级根目录 `package.json` 对 `@openlearn/plugin-sdk` 的依赖为 `^3.5.2`；
- 在 `scripts/publish.sh` 中前置注入 `pnpm lint` 与防漂移测试强制门禁；
- 修正插件开发规范文档中对 SemVer 0.x 版本的示例与约束指引。

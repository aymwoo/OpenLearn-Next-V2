# Release Notes v0.2.9

**发布日期**: 2026年9月5日

## 主要更新

### 1. html-applet 组件增强
- **统一渲染组件**：抽取 `<HtmlAppletFrame>`（`src/features/whiteboard/components/HtmlAppletFrame.tsx`），画布内嵌、全屏渲染器、默认兜底渲染器三处复用，按优先级解析四种内容源：`coursewareUuid` → `resourceId` → 插件自定义内容源 → `code`（`srcDoc`）。
- **类型契约补全**：`HtmlAppletPayload` 新增 `resourceId` / `sourceType` / `sourceId`，并修复 `buildElementData` 字段丢失与 `title` 渲染；新增 `src/types/lms-bridge.ts` 声明 `window.LMS` / `__LMS_STUDENT__` / `__LMS_COURSEWARE__`。

### 2. 插件内容源扩展
- 新增 `coursewareSourceRegistry` 与 `ctx.ui.registerCoursewareSource` / `unregisterCoursewareSource`（所有权感知 + 停用自动清理），插件可为 html-applet 接入第三方课件平台 / 私有资源网关；SDK 导出 `CoursewareSourceLoader` 类型。

### 3. LMS Bridge 双向通信
- `window.LMS` 新增 `on` / `off` / `setConfig` / `getProgress`；宿主新增 `sendCommandToCourseware(iframe, event, payload)`；后端新增 `GET /api/courseware/attempts/:attemptId/progress` 进度恢复接口。
- 课件 `submitted` / `progress_saved` / `event_logged` / `config_reported` 发布到前端 EventBus（`courseware.` 前缀经 Socket 转发到后端），后端 log 路由发布 `courseware.event_logged`，供 AI Agent 与插件订阅分析。

### 4. 备课画板组件配置增强
- `EditFieldKind` 新增 `select`（支持静态 `options` 与动态 `loadOptions`），`PaletteCardEditModal` 支持下拉选择；html-applet 的 `coursewareUuid` / `resourceId` 可在备课画板直接选择。

### 5. 安全与性能
- iframe 新增 `credentialless` 与 `referrerPolicy="no-referrer"`；`injectLmsSdk` 防御性移除 `<base>` 与 `<meta http-equiv=refresh>` 导航逃逸向量。
- iframe 懒挂载（IntersectionObserver，200px 预加载边距）+ 同时挂载上限 4 个（`courseware-frame-limiter.ts`）。

## 版本说明

- 平台 `openlearn-next` 升至 **0.2.9**。
- `@openlearn/plugin-sdk` 升至 **3.5.2**（新增 `CoursewareSourceLoader` 类型）。
- 全量自动化测试套件 171 文件 / 951 用例 100% 通过。

# Release Notes v0.7.7

**发布日期**: 2026年10月28日

OpenLearn V2 **v0.7.7** 是 v0.7.6 之后的**功能与补丁版本**：重点落地了第三方插件双轨制 UI 架构（Phase 1 可视沙箱容器与双向视图桥接），增强插件受信模式支持（通配符与前端 inline 执行），放行白板第三方插件图元，修复多处扩展点渲染与生命周期缺陷，重构根目录文档与架构索引，并全面同步全仓文档体系。

> **v0.7.6 → v0.7.7 共 17 个提交、56 个文件（+2,770 / −3,728）**。不含新增数据库迁移（沿用 44 个 `.sql`），不含 SDK 变更（`@openlearn/plugin-sdk` 保持 3.7.4，`@openlearn/plugin-test-kit` 保持 3.3.3）。

## 一、第三方插件双轨制 UI 架构（Phase 1，#344）

### 1.1 背景与痛点

第三方插件在受控进程隔离模式（`process`）下运行，前端仅能运行于隐藏沙箱 iframe 中。此前插件即使在 `manifest.json` 中声明了 `teacher.tab` 或 `teacher.panel` 等插槽贡献，宿主界面也只能渲染空白占位，第三方插件无法为教师端提供任何自定义可视化页面。

### 1.2 解决方案与能力

1. **声明式视图挂载**：
   - Manifest `contributes["teacher.tab"]` 与 `contributes["teacher.panel"]` 新增 `view` 字段（例如 `"view": "dashboard.html"`）。
   - 宿主在 `PluginTabPanel` 与 `ExtensionPointRenderer` 中为第三方视图创建独立的可视沙箱 iframe。
2. **严格安全隔离基线**：
   - iframe 采用严格沙箱策略（`sandbox="allow-scripts allow-forms allow-downloads"`，**无 `allow-same-origin`**），处于不透明源（opaque origin）。
   - 静态服务 `/plugins/*` 支持多维安全鉴权，并强制为 HTML 视图注入专用 CSP 响应头（`frame-ancestors 'self'`）。
3. **双向视图桥接 (View Bridge)**：
   - 视图内引入轻量客户端脚本 `/plugin-sandbox/view-bridge.js`，通过 `window.OpenLearnPluginBridge` 实现父子窗口受控通信。
   - 具备完整 API 支持：初始化握手 `onInit(ctx => ...)`、上下文同步 `onContextUpdate`、提示框 `bridge.ui.toast(...)`、容器自适应 `bridge.ui.resize(...)`、插件命令受控转发 `bridge.invokeCommand(...)`、数据存储 `bridge.storage.*` 以及 API 网关代理 `bridge.api.*`。
4. **四级渲染优先级**：
   - 统一调度：`React 组件 (内置) > DOM render 函数 (内置) > View 沙箱 (第三方) > 空态占位`。

## 二、插件信任与隔离增强

1. **`OPENLEARN_TRUSTED_INLINE_PLUGINS` 支持通配符**：
   - 支持 `*`（全局放行进程内）与 `前缀*`（如 `@ext/*`、`openlearn-plugin-*`），避免自研插件本地反复装卸时频繁修改白名单。
   - 系统插件判别（`isSystemPluginRecord`）保持精确匹配，防止通配符意外锁定第三方插件导致无法更新或卸载。
2. **前端远程插件支持 `inline` 模式**：
   - 受信插件经服务端判定为 `inline` 时，前端通过 Blob URL 进行动态 `import()`，直接挂载到宿主页面共享渲染树，支持使用宿主 React 依赖。
3. **安装向导隔离策略交互修复**：
   - `PluginInstallWizard` 对接 `/api/plugins/isolation-policy` 动态鉴权，对受信插件放行三档隔离选择，避免此前被硬编码锁定为 `process` 模式。
4. **安全加固**：
   - 废除前端直接采信 `manifest.executionMode` 的逻辑，全量以服务端计算的真实隔离模式为准，防止第三方包伪造字段同源越权。

## 三、白板与扩展点缺陷修复

1. **白板放行插件贡献图元**：
   - 扩展白板图元类型校验，放行带命名空间前缀或插件注册表声明的互动图元，解决第三方课件互动板无法绘制到白板的问题。
2. **调色板缺省配置防御**：
   - 调色板贡献项在 `editFields` 或 `color` 缺失时提供兜底安全默认值，避免教师编辑弹窗抛出 TypeError 崩溃。
3. **扩展点探针 Fiber 隔离**：
   - 探针检测第三方扩展点组件时临时屏蔽 React Current Dispatcher，避免普通函数组件挂载 hook 污染宿主 Fiber 树（修复 React error #300）。
4. **大模型工具箱生效 `exposeToAgent: false`**：
   - 修正 `buildOpenAITools` 过滤机制，避免未授权或内部敏感命令泄漏进大模型 Function Calling 工具列表中。

## 四、构建、运维与全仓文档体系同步

1. **前端构建产物安全**：
   - `vite build` 默认不再输出 `.js.map`，避免线上环境泄漏源码细节；新增 `SOURCE_MAP=1 pnpm build` 按需开启。
2. **PM2 配置环境变量补全**：
   - `ecosystem.config.cjs` 补全 `OPENLEARN_ALLOW_UNSIGNED` 与 `OPENLEARN_TRUSTED_INLINE_PLUGINS` 透传。
3. **文档体系更新与 0 漂移**：
   - 根 README 全面精简重构，提炼平台六大核心维度。
   - 清理根目录 9 个过时的历史审计报告快照。
   - 新增《第三方插件可视沙箱视图开发指南》，更新能力边界矩阵与清单规范。
   - 登记 `SOURCE_MAP` 构建变量至系统配置规范，全仓架构审计与环境变量比对达成 **`drift_count=0`**、**`env_drift=0`**。

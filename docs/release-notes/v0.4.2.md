# Release Notes v0.4.2

**发布日期**: 2026年9月27日

OpenLearn V2 **v0.4.2** 是 v0.4.1 的**内核治理补丁 (Kernel Governance Patch)**，落地审计清单 P2 剩余真实项：前端插件熔断器与 AI 上下文提供者。

---

## 一、前端插件熔断器（Circuit Breaker）

- `ExtensionErrorBoundary` 升级：每个扩展点渲染异常按 `pluginId` 连续计数（阈值 3 次 / 5 分钟滑动窗口），达到阈值**自动停用插件**（`deactivatePlugin`）并输出健康告警。
- 成功渲染清零连续计数；已熔断插件跳过渲染 + 去重告警；重新激活插件即恢复。
- 防止单个坏插件前端反复崩溃拖垮整页（此前仅有隔离边界、无降级动作）。

## 二、AI 上下文提供者（ai.context.provider）

- 新增 `server/ai-context-registry.ts` 注册表（kernel `AIService` 启动时 bind 委托）。
- Inline 插件经 `ctx.services.ai.registerAIContextProvider(id, fn)` 注册 AI 上下文切片提供者：`fn` 为服务端闭包，按 `lessonId` 返回插件实时状态（如「学生当前的语法错误调用栈」）。
- `/api/agent/chat` 组装 system instruction 时逐个调用并以 `[Plugin Context · <id>]` 段注入；单个提供者故障 try/catch 隔离，不影响对话。
- Worker 序列化边界：函数闭包无法跨线程，该能力仅 Inline 插件可用（接口声明为可选方法，插件可探测降级）。

## 三、范围内存量收敛

- `ExtensionPointRenderer` 存量 rules-of-hooks 违规修复（hooks 无条件前置）。
- `LazyWhiteboard` / `canary-ui` 的 `@ts-ignore` 清理（release gate 收敛）。
- 事件命名对齐「过去式」规范（`classroom:feed_appended`）；`.gitignore` stash 遗留冲突标记清理。

# Release Notes v0.2.1

**发布日期**: 2026年7月29日

## 主要更新

### 1. 交互网页课件与插件工具箱集成
- **工具栏快捷入口**: 白板工具栏中新增「交互网页课件 / HTML Applet」专属入口按钮。
- **画板与工具箱挂载**: 第三方插件注册的 `classroom.tool` 扩展点动态展现在 `LessonPalette` 中，教师可直接将插件组件插入画布。

### 2. 插件安装向导体验优化 (`PluginInstallWizard`)
- **⚡ 一键极速安装 / 更新**: 一键自动批准所需权限，接受降级/热更新警告并完成安装。
- **风险等级颜色编码**: 在权限审计步骤中按高（rose）、中（amber）、低（emerald）风险分级高亮显示。

### 3. 跨域沙箱与安全增强
- **`postMessage` 通用容错防护**: 对 `targetOrigin: 'null'` 的跨域 window 调用强行修正为 `'*'`，解决沙箱 `<iframe>` 中的跨域通信报错。
- **CSP `frame-src` 配置**: 允许 `'self'`, `blob:`, `data:`, `http:`, `https:` 等源的课件嵌入。

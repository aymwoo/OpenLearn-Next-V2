# Release Notes v0.1.11

**发布日期**: 2026年7月25日

## 主要更新

- 插件系统 (P7-A2)：完成统一插件运行时重构，将真实能力接入 `PluginCapabilityGateway`，经统一门面（`IPluginLifecycleManager` / `IPluginDistributionManager` / `IUnifiedExtensionRegistry` 等）暴露，并通过 `@openlearn/plugin-sdk` 对外提供。
- 用户中心：右上角收敛为圆形头像按钮 + 下拉菜单（个人资料 / 安全登出）；个人资料支持编辑显示名；新增修改密码流程（教师 / 学生双分支）。
- 班级管理：班级列表折叠行新增信息摘要 chip（学生人数 / 课程数 / 作业数），无需展开即可查看。
- 仪表盘 Activity Center：实时进行中状态、暂停/恢复与进入课堂控制、浅色主题。
- 班级花名册：新增列表视图与网格布局。
- 导航与路由：平台导航分组分类 + 徽标 + registry adapter；浏览器地址栏经 hash 路由反映当前页面。
- 文档：完成 25 目录权威文档中心升级；重构插件开发 AI Skill 指南以匹配最新 V2 架构。
- 修复：修正仪表盘 Activity Center 永久加载问题；plugin-sdk 构建改为 externalize npm 依赖，修复运行时 `Dynamic require of "path"` 错误。
- 清理：清除非系统插件产物并清理插件构建清单（移除 quiz-pro 等已清理插件条目）；plugin-sdk 引用升至 3.4.1。
- 审计与提案：新增平台基础审计报告、导航（PF-02）审计报告、文档质量评审报告与插件系统重构提案（P7-A2）。

## 版本说明

- 平台 `openlearn-next` 由 0.1.10 升至 **0.1.11**（patch）。
- `@openlearn/plugin-sdk` 维持 **3.4.1**，`@openlearn/plugin-test-kit` 维持各自独立版本，三者互不联动。

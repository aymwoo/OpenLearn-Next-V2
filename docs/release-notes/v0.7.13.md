# Release Notes v0.7.13

**发布日期**: 2026-11-08

v0.7.13 引入第三方教学增强套件插件 `ext-interactive-lab`，并放宽多媒体请求体限制。

## Features

- **虚拟探究实验与班级对抗竞赛套件（`ext-interactive-lab`）**：
  - 白板自定义图元 `ext-lab/circuit-simulator` 与沙箱视口内的欧姆定律交互仿真；
  - 自定义教学环节 `segment-inquiry-lab` 与门禁规则 `gate-circuit-verified`，服务端注册 `circuit.*` 只读/提交命令；
  - 自定义教学模式 `mode-arena-compete`，在开课门户展示；
  - 标准 ZIP 打包脚本与全链路集成测试（上传、激活、教学模式落库、CSP、门禁闭环、停用回收）。

## Fixes

- **请求体体积限制**：新增 30MB 中等上传白名单，覆盖头像、课表 OCR、站点 Logo、带附件 AI 对话；`/api/resources` 走 110MB 大文件白名单。
- **413 语义统一**：body-parser 的 `entity.too.large` 映射为 `PAYLOAD_TOO_LARGE`。

## Docs

- 新增 `DOCS_INDEX.md`；清理 6 份已完成的历史审计/整改台账。

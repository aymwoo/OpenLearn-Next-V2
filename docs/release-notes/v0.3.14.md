# Release Notes v0.3.14

**发布日期**: 2026年9月9日

OpenLearn V2 **v0.3.14** 是一次**补丁发布 (Patch Release)**，修复 `npx openlearn-next` 运行时无法解析可选依赖 `xlsx` 的告警问题，并包含教师端模拟学生交互体验修复。

---

## 变更内容

### 1. 修复 xlsx 可选依赖解析失败 (Cannot find package 'xlsx')
* **问题现象**：
  通过 `npx openlearn-next` 启动平台时，控制台打印告警：
  ```text
  [PluginHost] xlsx not available (optional): Cannot find package 'xlsx'
  imported from .../node_modules/openlearn-next/dist/server.cjs
  ```
* **根因分析**：
  `xlsx` 被误声明为 devDependency。服务端 bundle 以 `--packages=external` 构建，`import('xlsx')` 被保留为运行时动态导入；而 devDependency 不会随发布包安装到消费者环境（含 npx 缓存目录），导致动态导入失败。
* **修复**：
  将 `xlsx` 从 devDependencies 移至 dependencies，确保运行时动态导入可解析，插件共享模块正确注册 Excel 导入导出能力。

### 2. 教师端模拟学生（Student View）返回教师端交互修复
* 新增常驻全局模拟学生横幅（Top Impersonation Banner）及【退出模拟并返回教师端】操作；
* 顶部导航栏接入 `setActiveRole`，增加【返回教师端】快捷操作按钮；
* 完善 `AppHeader.test.tsx` 单元测试。

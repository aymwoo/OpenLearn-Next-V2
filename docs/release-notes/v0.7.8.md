# Release Notes v0.7.8

**发布日期**: 2026年10月30日

OpenLearn V2 **v0.7.8** 是 v0.7.7 之后的**功能与补丁版本**：重点落地了 AI 插件开发手册体系（`docs/agent/` 子树与机器可读架构事实契约），优化插件中心卡片布局与响应式操作栏，强化全班专注锁定下的学生端浮层与沙箱视图防护，全面提升全站中文排版可读性与字号底线，并在白板属性栏、生生互评赏析大屏、PPTX 课件与开发态访问日志等多处治理顽固缺陷。

> **v0.7.7 → v0.7.8 共 22 个提交、80+ 文件变更**。包含 1 个新增数据库迁移（`044_students_gender.sql`，学生性别与头像扩展），SDK 保持 `@openlearn/plugin-sdk@3.7.5` / `@openlearn/plugin-test-kit@3.3.3`。

---

## 一、AI 插件开发手册体系与架构契约落地（#351, #358）

### 1.1 `docs/agent/` 开发手册子树

为支持通过大模型/智能体（AI Agent）端到端开发与排查 OpenLearn 插件，全面上线 `docs/agent/` 手册子树（27 个页面）：

- **核心入口**：`agent-handbook.md` 明确三类插件（Server-Only、Sandbox-View、Full-Stack）典型开发范式与核心限制。
- **排查手册（Playbook）**：总结高频崩溃与坑点指南，涵盖 CSP 拦截、生命周期死锁、Token 解析异常等常见问题。
- **架构参考（Reference）**：详尽收录 Manifest、PluginContext、命令与事件、数据库 API、HTTP API、前端沙箱与版本迁移指引，每篇顶部均标注「与 LLM 先验冲突」提示。

### 1.2 机器可读事实表与防漂移机制

- `docs/agent/contracts/` 收录从源码动态抽取的机器可读契约：`capabilities.json`、`contributes-groups.json`、`tokens.json` 与 `versions.json`。
- 新增 `audit-tools/agent_facts.py` 工具，支持 `--check` 比对文档声明与平台源码实现是否发生漂移，全面接入 `bash audit-tools/run.sh` 门禁。

### 1.3 六大架构契约与安全红线沉淀

在 `docs/reference/plugin-architecture-contracts.md` 中系统梳理并沉淀了平台六大防护规范：

1. **布局与自适应契约**：收敛 `Panel`、`WhiteboardWidget`、`FloatingOverlay`、`ActionItem` 四档布局语义矩阵与容器高度自适应伸缩通信协议。
2. **白板图元双轨制扩展**：明确矢量绘制与沙箱视图双轨选型，严禁第三方插件 SQL 直写白板核心表。
3. **课堂运行时生命周期**：确立班级上下文空值防御范式与切班数据重载流程。
4. **SQL-Guard 安全红线**：公开 36 张核心受保护表硬黑名单及危险 SQL 语法拦截规则。
5. **ServiceHost 三重安全门禁**：公开 Token 白名单、空 capability 降级只读锁定与细粒度策略校验机制。
6. **网关限流与客户端防抖**：规范全局写限流、课堂独立限流桶与插件网关分流机制。

## 二、插件中心卡片布局与响应式操作栏优化（#360）

1. **主次操作分级**：
   - 插件商店卡片主操作栏聚焦核心高频操作——「启用/禁用」与「总览」开关。
   - 一键更新仅在检测到新版本发布时显式高亮呈现。
   - 次级与低频操作（插件设置、上传更新包、一键迁移、卸载插件）优雅收敛至右侧「更多操作 (···)」下拉菜单中，减少视觉干扰。
2. **紧凑元数据排布**：
   - 开发者与安装时间采用单行 `nowrap` 紧凑排布，消除多行折行杂乱感。
   - 针对具备配置项、更新源或迁移能力的插件动态展示对应菜单项。
3. **声明式与纯 View 插件时序优化（#350）**：
   - 将 `registerManifestContributions` 注册时序前移至加载 `frontend.js` 之前，确保脚本加载失败时声明式贡献依然保留。
   - 解开无前端脚本的纯 view 插件拦截限制，允许声明式卡片与 Tab 顺利激活运行。

## 三、全班专注锁定与学生端交互防护

此前全班专注锁定仅作用于教师与学生白板交互，学生端浮层卡片与插件视图在锁定期间仍可操作。

1. **沙箱 iframe 视图防护透传**：
   - `ExtensionPointRenderer` 支持 `locked` 属性透传：
     - **panel 槽位**：自动覆盖半透明拦截遮罩，提示「全班专注锁定中，插件视图已暂停交互」。
     - **floating 槽位**（如便签浮层）：自动收起折叠并保留展开徽标，且 iframe 容器保持挂载，不丢失插件内部输入状态。
2. **课堂节奏晴雨表锁定**：
   - `StudentInteractiveOverlay` 在全班锁定期间禁用全部四个反馈按钮并展示锁定标识，确保课堂授课秩序。
   - 完善 E2E 黄金旅程自动化测试闭环，覆盖教师端锁定与解锁交互流。

## 四、排版体系与中文视觉体验全面升级（#361）

1. **全站最小字号底线提升至 13px**：
   - 将全站微型字号（`text-[6px]` ~ `text-[12.5px]`）的物理防线下限从 12px 提升至 13px，彻底解决汉字笔画密集粘连发虚的痛点。
   - Tailwind v4 `--text-xs` 令牌平滑升级至 `0.8125rem` (13px)，并在全局 CSS 中加入防缩放跌破 12px 的保护机制。
2. **互动课堂 (live_class) 界面视觉重心均衡**：
   - 学生专注力监控区、大纲区等小标签由 9px~~10px 提升至 11px~~12px，配合微内边距提升笔画饱满度。
   - 收敛互动大屏与统计卡片中的过大字体，按黄金比例规范标签与数值排布，消除视觉压迫感。
3. **现代中文无衬线字体栈**：
   - 显式配置苹方、冬青黑体、微软雅黑等优先字体栈，并将 HTML 根语言修正为 `zh-CN`。

## 五、白板与系统核心缺陷治理

1. **白板内置组件移除手动尺寸输入（#356）**：
   - 针对 quiz、assignment、rollcall 及插件组件等由窗口卡片渲染的内置组件，收敛属性编辑器，隐藏「尺寸」卡片，防止用户误输入导致 50px 畸形卡片。
   - 课件属性弹窗同步收敛，去除预设尺寸按钮与强制写入逻辑。
2. **学生专注力监控卡片姓名与头像增强（#357）**：
   - 移除姓名 48px 圆形头像内嵌与省略号截断限制，独立一行完整渲染中文姓名。
   - 新增 `044_students_gender.sql` 数据迁移，支持学生性别属性；新增 `StudentAvatarVisual`，按个人照片 > 性别头像 > 中性人像优雅降级展示。
3. **PPTX 课件渲染防死循环单例化**：
   - 提取 `PPTX_VIEWER_CUSTOMIZATION` 与 `PPTX_AVAILABLE_LOCALES` 顶层单例，消除微秒级频繁触发 `Maximum update depth exceeded` 导致的崩溃异常。
4. **焦点作品赏析单作品空指针防线**：
   - 修复生生互评赏析大屏在班级仅有 1 份提交作品时访问 `workB.studentName` 抛出 TypeError 的致命异常，提供优雅虚线占位与空安全兜底。
5. **课堂视图回写 429 限流治理**：
   - 为 `POST /api/classroom/sessions/:lessonId/view-state` 配置独立限流桶（120次/分），并调优前端 Diff 去重逻辑，杜绝高频翻页误判 429。
6. **开发态访问日志静默治理（#355）**：
   - 将 Vite 开发缓存目录 `/.vite-cache/` 加入访问日志静默名单，消除冷启动编译慢请求刷屏问题。

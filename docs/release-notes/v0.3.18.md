# Release Notes v0.3.18

**发布日期**: 2026年9月19日

OpenLearn V2 **v0.3.18** 是一个**AI架构解耦治理、视觉规范对齐与平台体验优化版本 (AI Decoupling, Visual Harmonization & Platform Experience Release)**。本版本彻底移除了历史遗留的 Gemini 硬编码默认回退，强制推行基于 OpenAI 兼容协议的多 AI Provider 动态配置体系；完成了系统侧边栏紧凑与分类折叠重构，优化了管理后台视觉风格；规范了全站中文字体排版并建立 9pt (12px) 物理底线保护与无障碍缩放能力；全面统一产品品牌命名为 "OpenLearn Next"；并修复了仪表盘 500 异常与加固了测试套件并发鲁棒性。

---

## 一、AI 架构解耦与动态 Provider 治理

### 1. 彻底移除默认 Gemini 回退与依赖清理

- **解耦硬编码回退**：服务端与内核全面清理 `process.env.GEMINI_API_KEY` 兜底以及 `@google/genai` 运行时依赖，系统 AI 能力统一由数据库 `ai_providers` 中动态配置的 OpenAI 兼容提供商（如 DeepSeek、Qwen、Ollama、OpenAI 等）驱动。
- **环境与部署配置清理**：清理 `.env.example`, `docker-compose.yml`, `ecosystem.config.cjs`, `deploy.sh`, `cli.mjs`, `metadata.json` 中的 `GEMINI_API_KEY` 与遗留声明。

### 2. 内核 DI 服务强化与凭据透明解密

- **内核 AI 服务收口**：`packages/core/di/ai-service.ts` 与 `AIProviderGateway` 严格要求已配置的提供商，在未配置有效 Provider 时统一抛出友好中文提示（`当前系统未配置任何 AI 提供商，请联系管理员前往「系统管理 -> AI 提供商管理」添加模型配置后使用。`）。
- **凭据透明解密**：集成 AES-256-GCM 密钥透明解密机制，确保存储于 SQLite 的敏感 API Key 自动安全解密后透传给模型网关。

### 3. 全局业务路由收归内核服务

- **业务模块统一迁移**：`assignments.ts`（测验生成、作业智能批阅）、`lessons.ts`（白板 AI 助教）、`grading.ts`（学期综合评估）、`schedules.ts`（课表 OCR）与 `ai-submit-injector.ts` 全面移除 Gemini 回退分支，统一收归内核 `kernelContainer.aiService`。

### 4. 前端交互引导与未配置状态机防御

- **智能助教侧边栏 (`RightSidebar.tsx`)**：移除写死的“系统默认（Gemini）”选项；无提供商时展示“未配置 AI 提供商”禁用选项，并在抽屉顶部展示醒目琥珀色警示卡片引导前往「系统管理 -> AI 提供商管理」，同时禁用输入框与发送按钮。
- **课表 OCR 识别 (`TimetableOcrView.tsx`)**：移除默认选项，无提供商时显示多模态模型要求引导横幅并禁用 OCR 识别按钮。
- **全局状态机同步 (`App.tsx` & `useAgentChat.ts`)**：修正 `agentProviderId` 初始状态机与同步逻辑，消除对 `'system'` 伪提供商的隐式依赖。

## 二、界面视觉与交互重构

### 5. 现代化紧凑导航边栏与分类折叠交互

- **紧凑排版与现代无边框视觉**：导航边栏宽度缩小为贴合项目文字宽度的紧凑尺寸，移除突兀深黑边框，升级为柔和阴影与半透明底色现代设计。
- **分类折叠与视觉层级区隔**：导航条目分类（如教学工具、系统管理等）支持点击折叠/展开，带平滑动画与状态记忆；条目文字“帮助与支持”统一精简为“帮助支持”。

### 6. 管理后台页面风格规范化对齐 (`AdminPanel.tsx`)

- 重构 `AdminPanel.tsx`，将旧式高对比黑边框与深色底框统一调整为与教师端其他页面一致的现代白底、轻质灰边（`border-gray-200/80`）与柔和阴影风格。

### 7. 全平台品牌规范对齐 (OpenLearn Next)

- 将系统内所有历史遗留的 "Edu OS"、"EduLearn OS"、"EduLearn LMS" 标识全面对齐为统一产品命名 "OpenLearn Next"。

## 三、排版规范与无障碍设计

### 8. 全站中文字体规范化与 9pt (12px) 物理保底

- **中文排版底线标准**：根据现代中文网页排版规范与印刷字号换算标准（$9\text{pt} = 12\text{px}$，中文小五号字），杜绝页面中因字号过小导致的中文字符发虚与可辨认度下降。
- **全局 CSS 强防御兜底 (`src/index.css`)**：在全局样式表中配置 `max(12px, calc(12px * var(--app-font-scale, 1))) !important` 规则，确保即使用户选择紧凑缩放模式（85%），全站文字依然严格受 12px 物理底线保护。
- **全站微像素类名升级**：对全平台 70+ 个页面与组件中的 748 处微像素类名升级为标准 Tailwind `text-xs` 或 `text-sm`，并同步将所有 Recharts/SVG 图表刻度与提示框字体统一提升至 12px。

### 9. 全局字体缩放无障碍辅助功能

- **状态管理与穿透生效**：基于 Zustand 构建 `fontSizeStore`（80% ~ 150% 持久化），通过 `--font-scale` 变量联动根节点，并向所有沙箱课件 `iframe` 广播字号缩放指令（`broadcastFontScaleToIframes`）。
- **顶栏快捷控制**：在全局顶栏集成快捷调节器，并移除非顶部的冗余按钮，保障操作界面纯净统一。

## 四、缺陷修复与测试稳定性

### 10. 仪表盘加载 500 异常与 Worker 插件命令注册修复

- **缺陷修复**：

### 11. 测试套件时间预算与并发鲁棒性加固

- 对 `worker-runtime/integration.test.ts`、`AppShell.test.tsx`、`LazyCourseware.test.tsx` 动态预热与预算扩充，抵御高并发负载环境下的定时器击穿与抖动，全量 205 个测试文件、1221 项单测保持 100% 稳定通过。

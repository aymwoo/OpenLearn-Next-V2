# Release Notes v0.3.15

**发布日期**: 2026年9月17日

OpenLearn V2 **v0.3.15** 是一次重要的**特性与安全补丁发布 (Feature & Security Patch Release)**，正式引入了 **LTI 1.3 (IMS Learning Tools Interoperability 1.3 / LTI Advantage) 协议支持与第三方安全会话桥接体系**。该版本使 OpenLearn 能够以独立插件形式无缝嵌入 Canvas、Moodle、Blackboard、Sakai 等主流学习管理系统 (LMS)，实现基于 OIDC 3-Legged 流程的免密单点登录与沉浸式内嵌教学，同时严格守卫跨域会话安全边界与沙箱防点击劫持防线。

---

## 核心新特性与架构升级

### 1. Iframe 嵌入安全管控与动态 CSP 放行 (`server.ts`)

- **LMS 来源白名单配置 (`LTI_ALLOWED_LMS_ORIGINS`)**：
  服务端支持通过环境变量 `LTI_ALLOWED_LMS_ORIGINS` 配置受信任的 LMS 来源（多个域名以逗号分隔，例如 `https://canvas.instructure.com,https://moodle.edu.org`）。
- **动态 Content-Security-Policy 调控**：
  - 当配置了合法域名列表时，平台自动放行 CSP `frame-ancestors` 指令，并动态移除原有的 `X-Frame-Options: SAMEORIGIN` 阻断头，允许平台在授权的 LMS Iframe 容器中流畅加载；
  - 当未配置任何外部来源时，平台依然保持严格的同源安全防御（`X-Frame-Options: SAMEORIGIN; frame-ancestors 'self'`），防范任意外部网站的点击劫持（Clickjacking）攻击。

### 2. 平台统一会话桥接服务 (`IAuthSessionBridgeService`)

- **特权身份同步与会话下发**：
  在内核依赖注入（DI）容器中注册统一的认证会话桥接服务 `IAuthSessionBridgeService`（由 Token `IAuthSessionBridgeToken` 导出并开放给认证类插件）：
  ```typescript
  const bridge = ctx.services.get(IAuthSessionBridgeToken);
  const { sessionToken, user } = bridge.createSessionForUser({
    username: 'lti_canvas_1002',
    name: 'Jane Doe',
    email: 'jane@example.edu',
    role: 'student', // 自动映射为 student / teacher / admin
    provider: 'lti13:canvas.instructure.com',
  });
  ```
- **用户即时自动配置与关联 (JIT Provisioning)**：
  桥接服务自动检查外部 LMS 用户的存在性，并在必要时安全完成用户档案建档、角色绑定与 `client_sessions` 令牌持久化。

### 3. 网关跨域会话 Cookie 安全注入与特权守卫 (`PluginApiGateway`)

- **透明会话凭证注入与特权门禁**：
  扩展插件网关契约 `PluginApiResponse` 支持声明式 `sessionToken` 属性，并通过特权安全门禁守卫，仅允许在 Manifest `requires` 中声明了 `IAuthSessionBridgeService` 的可信认证插件触发 Cookie 注入，未声明特权的普通插件即便返回 `sessionToken` 也会被网关阻断。
- **第三方 Cookie 严格防护与同源防御**：
  - 插件在 Worker 隔离线程内部无法直接篡改 Express 响应头。当插件在认证响应中返回 `sessionToken` 时，主线程网关自动写入符合跨域 Iframe 现代浏览器安全规范的 Cookie：
    `Set-Cookie: edu_os_token=...; Path=/; HttpOnly; SameSite=None; Secure; Max-Age=86400`；
  - 网关严格剥离非授权插件常规 `headers['set-cookie']`，彻底杜绝任意插件伪造或劫持宿主 Cookie 凭据。

### 4. 官方参考插件研发 (`@openlearn/plugin-lti-provider`)

- 提供开箱即用的 LTI 1.3 Tool Provider 参考插件：
  - **`/login` OIDC 启动端点**：解析 LMS 发起的 3-Legged OIDC 认证请求，基于 SQLite 状态机生成带有效期的高熵 Nonce 与 State 并防御重放攻击；
  - **`/launch` 启动核验端点**：接收并解包 LMS 提交的 `id_token`，校验 RS256 签名、Issuer、Audience 及 Nonce，自动通过会话桥接完成身份登录并无缝重定向进入课堂；
  - **`/jwks` 公钥集端点**：自动托管并输出标准 RFC 7517 格式的 JWKS 公钥集合，供 LMS 平台核验本系统签名的 Token。

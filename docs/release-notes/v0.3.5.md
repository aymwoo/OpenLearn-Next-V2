# Release Notes v0.3.5

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.5** 是针对插件生态引擎兼容性与生产路由健壮性的**重要架构对齐补丁**。本版本全量放宽了内置核心插件与脚手架模板的 `engines.openlearn` 约束，消除了 SemVer 0.x 阶段版本升级引发的插件互锁拒载异常，并修复了 SPA 静态文件回退路由对健康检查探针接口的拦截问题。

---

## 主要更新

### 1. 内置核心插件引擎约束全面放宽
- **SemVer 0.x 互锁消除**：根据 SemVer 规范，`^0.2.5` 严格限定于 `<0.3.0`，导致平台升级至 0.3.x 时合法内置插件无法加载；
- **全量升级兼容**：将 7 大内置插件（`builtin`、`vfs`、`process`、`management`、`ai-planner`、`ai-submit-injector`、`assignment-eval`）及插件 SDK 脚手架模板中的 `engines.openlearn` 调整为向上兼容的 `>=0.2.5`。

### 2. SPA 路由与健康探针层级校正
- **探针放行**：调整路由挂载顺序，将 `/health`、`/health/ready`、`/metrics` 端点前置于 SPA 静态通配路由（`app.get('*', ...)`）之前；
- **消除误拦截**：彻底修复了生产独立部署环境下健康检查请求错误返回 `index.html` 导致探针失灵的缺陷。

### 3. 历史插件数据库恢复安全容错
- **Worker 目录存在性防护**：在 `worker-manager.ts` 恢复插件时增加磁盘物理路径存在性校验，若物理目录被清理则优雅回退至内存内嵌数据 URL 启动，避免了启动时的 `ERR_MODULE_NOT_FOUND` 报警。

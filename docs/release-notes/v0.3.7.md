# Release Notes v0.3.7

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.7** 引入了全新的**命令行缓存清理与数据安全重置实用工具（CLI Cache Cleaner）**。本版本专门解决教师与开发者在使用 `npx` 启动平台时，因本地 npm 缓存机制导致反复运行到旧版本包的问题，并提供了对本地运行临时文件与数据库的一键安全维护支持。

---

## 主要更新

### 1. NPX 历史缓存精准清理 (`clean` / `clean-cache`)
- **根因消除**：`npx` 会在用户主目录 `~/.npm/_npx/` 下缓存历史下载的包模块，导致有时即使用户期望最新版，依然命中旧缓存；
- **智能扫描与清理**：在 `cli.mjs` 与独立模块 `cli-cleaner.mjs` 中新增清理工具，自动遍历 `~/.npm/_npx/` 下所有哈希子目录，精确定位并删除 `openlearn-next` 历史包目录，绝不误伤其他 npm 工具缓存。

### 2. 运行时临时数据优化与主库安全保护
- **默认模式安全保障**：执行 `npx openlearn-next clean` 时，默认仅清理 SQLite WAL 预写日志 (`data.db-wal`)、共享内存文件 (`data.db-shm`) 与临时日志目录，**严格保护用户的业务核心数据库 `data.db` 不被误删**；
- **精细化控制选项**：
  - `--npx`：仅清理 NPX 远端包缓存，完全不触碰本地数据库与运行日志；
  - `--db`：重置本地业务数据库（下次启动自动全新初始化初始账号与默认插件）；
  - `--all`：全量彻底清理（NPX 历史包 + 运行日志 + 重置数据库）。

### 3. 增强帮助与版本查询
- 新增 `-v` / `--version` 快速版本打印；
- 提供格式清晰的 `-h` / `--help` 命令行交互指引。

---

## 常用命令速查

```bash
# 仅清理 NPX 历史包缓存（推荐发版后更新使用）
npx openlearn-next clean --npx

# 日常清理日志与临时数据（保留业务数据库）
npx openlearn-next clean

# 彻底重置所有本地数据并清理包缓存
npx openlearn-next clean --all
```

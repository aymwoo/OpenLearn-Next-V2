# Release Notes v0.3.13

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.13** 是一项关键的**制品打包协议与依赖解析热修复补丁 (Packaging Hotfix)**，旨在解决 `npx openlearn-next` 在终端用户环境中因 pnpm `workspace:*` 协议未展开而无法正常执行的问题。

---

## 缺陷根因与修复说明

### 1. `workspace:*` 协议展开失效 (EUNSUPPORTEDPROTOCOL)
* **问题现象**：
  在终端执行 `npx openlearn-next` 或通过 npm 安装时，npm 报错中断退出：
  ```text
  npm error code EUNSUPPORTEDPROTOCOL
  npm error Unsupported URL Type "workspace:": workspace:*
  ```
* **根因分析**：
  平台根目录对内部 `@openlearn/plugin-sdk` 采用了 pnpm 工作区协议（`workspace:*`）。此前发版流程直接调用了原生 `npm publish`，原生 npm 无法解析并转译该协议，导致打出的 tarball 中保留了非标准协议声明。
* **发布工程修复**：
  全流程标准化采用 `pnpm publish --no-git-checks`。pnpm 在打包生成制品时，会自动将所有的 `workspace:*` 依赖强解析并固化替换为符合 SemVer 规范的真实版本号（`3.6.0`）。

### 2. 发布工作流规范升级 (Release Workflow SOP)
* 同步更新 [`.agents/skills/openlearn-release-workflow/SKILL.md`](../developer-guide/developer-guide) 规范，将平台主包发布命令由 `npm publish` 永久修正为 `pnpm publish --no-git-checks`，从制度和工具链层面彻底杜绝同类隐患。

# Release Notes v0.6.0

**发布日期**: 2026年10月11日

OpenLearn V2 **v0.6.0** 是平台里程碑式的重要功能与生态扩展版本（**National Smart Education Interconnect & All-Domain Extension Slots Milestone**）。本版本完成了官方《国家智慧教育公共服务平台连接器》标杆插件的端到端落地，全域新开并消费 20 个业务扩展槽位（使全仓扩展槽扩充至 95 个并保持 0 幽灵槽位），实现了白板自定义图元一等公民渲染扩展、StageGuard 资源级物理强门禁以及排课与课时领域服务深度解耦。

---

## 一、官方《国家智慧教育公共服务平台连接器》（@openlearn/plugin-smart-edu）标杆插件落地

作为平台首个打通国家级教育资源生态的官方连接器插件，`@openlearn/plugin-smart-edu` 实现了从精品课检索、课程与白板图元原子化导入，到课堂学情向国家平台标准化上报与回执签发的端到端业务闭环：

1. **核心命令总线与内核事务落库**：
   - 在 `packages/plugins/national-smart-edu.ts` 实现内核级连接器插件，注册 `smart_edu.search_resources`、`smart_edu.import_course`、`smart_edu.report_metrics` 与 `smart_edu.get_status` 四大核心命令；
   - 预置高中信息科技（贪心排程算法）、物理（DIS 数字化动量守恒探究）与通用技术（闭环温控系统）三门国家级/部优精品课示范数据；
   - 课程导入支持 SQLite 级联事务写入 `lessons` 课时记录并基于完整 `uuidv7()` 生成白板图元（含实验组件、作业评价标准与测验），杜绝微秒级主键冲突；
2. **国家 CELTS-3 规范学情上报与回执签发**：
   - 学情上报支持综合评估课堂参与度、平均答题成绩与互动频次，签发包含 SHA-256 校验码的国家平台 CELTS-3 规范电子回执；
   - 上报成功后自动向全局 `eventBus` 广播 `smart_edu.metrics_reported` 领域事件；
3. **开放外部网关 REST API**：
   - 在 `server/routes/plugins.ts` 暴露 `/api/external/smart-edu/resources`、`/import`、`/report` 与 `/status` 四组直连网关路由；
4. **全域扩展槽位 10 个端点全覆盖装配**：
   - 备课工具栏槽 (`course.list.toolbar.action`)：集成 `SmartEduCourseToolbarAction`，一键唤出精品课分类检索与导入弹窗；
   - 课程卡片角标槽 (`course.card.badge`)：集成 `SmartEduCourseBadge`，高亮展示国家级/部优精品课金标徽章；
   - 课程卡片动作槽 (`course.card.action`)：集成 `SmartEduCourseCardAction`，提供一键向国家智慧教育云推送学情入口；
   - 环节动作槽 (`editor.segment.action`)：集成 `SmartEduSegmentAction`，支持环节微课资源插入；
   - 驾驶舱横幅槽 (`classroom.alert.banner`)：集成 `SmartEduAlertBanner`，播报国家云双师协同通道状态与网络预警；
   - 展台跑马灯槽 (`classroom.stage.display.ticker`)：集成 `SmartEduStageTicker`，在授课大屏滚动播放平台微课指引；
   - 课后导出槽 (`classroom.post_class.exporter`)：集成 `SmartEduPostClassExporter`，一键导出 CELTS-3 规范学情归档数据包；
   - 顶栏心跳胶囊槽 (`header.status_pill`)：集成 `SmartEduHeaderStatusPill`，以呼吸灯浮层形式呈现平台连通率与心跳延迟；
   - 管理看板卡片槽 (`admin.dashboard.card`)：集成 `SmartEduAdminCard`，在管理后台直连展示国家云接口多活看板；
5. **开箱即用与质量覆盖**：
   - 在 `src/main.tsx` 启动阶段自动调用 `registerSmartEduExtensions()`；
   - 内核命令测试（4/4）与前端连接器组件测试（8/8）全量绿灯通过。

## 二、全域 20 个业务扩展槽位全量落地（扩充至 95 个联合槽位，0 幽灵槽位）

为彻底解决业务功能与宿主界面高度耦合的问题，本版本在 14 个核心业务视图中开辟并消费了 20 个全新的扩展槽位：

1. **架构契约双源一致性（SSOT）与防漂移**：
   - 在 `src/plugin-host/types.ts` 中将 `ExtensionSlot` 联合类型扩充至 **95** 个；
   - 在 `packages/core/esm-loader/manifest-schema.ts` 为全部 20 个新槽位声明严格的 Zod 校验 Schema；
   - 同步更新 `packages/core/plugin-host/contribution-registry.ts` 与 `packages/plugin-sdk/index.ts`，并通过 `generate-dts.mjs` 重新生成 `packages/plugin-sdk/generated.d.ts`；
2. **14 个核心业务视图全量消费（0 幽灵槽位）**：
   - **备课与资源中心**：`course.list.toolbar.action`、`course.card.badge`、`course.card.action`、`editor.segment.action`；
   - **执教大屏与课堂互动**：`classroom.alert.banner`、`classroom.cockpit.drawer.item`、`classroom.stage.display.ticker`、`classroom.post_class.exporter`；
   - **课表与机房管理**：`timetable.toolbar.action`、`timetable.card.badge`、`computer_lab.toolbar.action`、`computer_lab.seat.overlay`；
   - **学生门户与作业中心**：`student.dashboard.hero_widget`、`student.assignment.toolbar.action`、`student.lesson.notes_addon`、`student.lesson.toolbox`；
   - **管理后台与系统底座**：`admin.dashboard.card`、`admin.user.action`、`header.status_pill`、`ai_sidebar.tab`；
3. **静态 Contributes 命令桥接打通**：
   - 在 `src/plugin-host/plugin-host.ts` 中将 `command_palette.item`、`quick_insert.item`、`ai.prompt.template`、`ai.skill.provider` 以及声明式 `classroom.tool` 桥接接入宿主 `/api/plugins/execute-command` 执行流水线；
4. **权威文档与门禁自动化保证**：
   - `docs/reference/plugin-ui-extension-slots.md` 全面对齐 95 个联合槽位与 8 个锚点槽位；
   - 双源一致性门禁与 SDK 防漂移门禁自动化守护。

## 三、白板自定义图元一等公民扩展槽位（`whiteboard.renderer`）

1. **核心渲染流水线接入**：
   - 在 `InteractiveWhiteboard.tsx` 的 `renderElement` 核心入口挂载 `whiteboard.renderer` 扩展点，允许第三方插件为特定图元类型（如 Desmos 函数曲线、GeoGebra 几何画板、分子 3D 结构等）注册专属渲染器；
2. **画板生命周期与数据协同打通**：
   - 自定义图元深度接入 Konva 视口缩放、平铺拖拽布局、选框高亮、右键上下文菜单与多选生命周期；
   - 注入 `onElementUpdate` 回调，图元变更时自动向 `frontendEventBus` 广播 `whiteboard.element_updated`，触发全班协同同步；
3. **无边框与自绘模式**：
   - 支持 `data.frameless = true` 与 `data.hideTitleBar = true`，图元可自由选择展示标准窗口外壳或完全自绘无边框视觉。

## 四、StageGuard 资源级物理强门禁与防跳关

彻底终结了原系统“仅防 UI 点击切换、不防直接调用 API 提交测验/作业”的旁路跳关隐患：

1. **多层级双向环节解析器 (`StageResolver`)**：
   - `resolveElementStageId` 与 `resolveAssignmentStageId` 多级解析白板图元、随堂测验与课后作业的归属教学环节；
2. **物理强拦截与 Fail-close 语义**：
   - 在 `server/services/diagnostic-service.ts`（测验提交）与 `packages/plugins/assignment-eval.ts`（作业提交）入库前调用物理门禁校验；未解锁环节直接抛出 HTTP 403 `STAGE_ACCESS_DENIED`，杜绝任何数据落库；
3. **教师与管理特权豁免**：
   - 教师与管理员在预览与调试课件时自动豁免门禁限制，兼顾安全性与教学教研体验。

## 五、领域服务解耦与三维排课冲突检测引擎（Architecture Decoupling E3）

1. **`ScheduleService` 领域服务下沉**：
   - 将 `server/routes/schedules.ts` 纯领域业务逻辑彻底抽离至 `server/services/schedule-service.ts`，路由代码精简 64%；
   - 引入三维排课冲突检测引擎（`detectConflicts`），精确校验班级时段相交（`class_overlap`）、教师跨班冲突（`teacher_overlap`）与机房共享冲突（`lab_overlap`）；
2. **`LessonService` 领域服务下沉**：
   - 将 `server/routes/lessons.ts` 纯数据访问与业务编排抽离至 `server/services/lesson-service.ts`，路由精简 48%；
   - 封装核心 IDOR 水平越权防范、单事务级联清理 10+ 张关联表以及课时活跃内存分段自动回收。

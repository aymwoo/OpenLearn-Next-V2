# Release Notes v0.7.0

**发布日期**: 2026年10月22日

OpenLearn V2 **v0.7.0** 是平台的**测评子系统全面落地与安全体系化加固版本 (Assessment Subsystem GA & Security Hardening)**。本版本将「测评」从数据模型一路交付到师生双端完整闭环（出题、布置、每人一卷、严格考试与防作弊、AI 辅助批改、难度/区分度项分析、存量数据迁移），并对外开放插件题型生态；同步完成插件签名分发、路由越权、IDOR/XSS、密钥与传输边界等系统性安全整改；新增全角色自动功能巡检（pnpm sweep）并接入 CI，将「上一正式版 → main」升级回归门禁纳入必跑作业。插件配置分层、统一 i18n 体系、声明式迁移与扩展插槽大批量扩充，标志着插件生态进入成熟期。

---

## 一、测评子系统全面落地（Issue #100 系列）

1. **子系统地基（数据模型 + 判分引擎 + REST API）**：新增 assessments / question_bank_items / assessment_items / assessment_assignments / assessment_attempts / assessment_answers 六表与前后端共用的纯领域层 packages/core/assessment/。组卷即快照（发布只改状态，删题库不影响已组卷内容）；以选项索引为权威的判分口径（多选全对满分 / 少选按命中比例 / 错选 0 分）；score: null 一律进人工批改队列，绝不兜底成 0 或满分；判分幂等且人工改分不被自动判分覆盖；标准答案经白名单序列化保证不出接口（哨兵单测门禁）；匿名问卷用 HMAC(ENCRYPTION_KEY, ...) 去重；超时惰性结算不引入后台定时器。
2. **教师端「测评中心」与学生端「我的测评」**：教师工作区覆盖试卷 CRUD、组卷、发布到班级、交卷进度、人工批改与统计导出；学生端覆盖待完成/已完成分组、5 种内置题型作答控件、1.5s 防抖自动保存、服务端计时倒计时、断线续答，结果页完全由服务端 showScore / showAnalysis 决定（未发布成绩不泄露答案）。
3. **严格考试模式与防作弊**：单次作答限制（已交卷/已批改 409）；按布置+学生确定性种子乱序题目与选项（刷新重连顺序一致）；全屏锁定、切屏/失焦/退出全屏事件实时上报并持久化到 proctor_json，教师端展示监考告警；考试模式默认不发布成绩，教师显式发布后学生可见。
4. **成绩回写与学期总评联动**：发布成绩或手动同步时原子回写 exams / exam_scores，经 GradingService 以 exam_weight 计入学期总评；仅回写带 assessment:{id} 前缀的记录，绝不覆盖教师手工录入的同名线下成绩。
5. **课内即时发起与大屏看板**：课堂会话中即时发起随堂测/考，Socket.IO 广播联动学生端全屏作答浮层；大屏与驾驶舱实时拉取全班作答进度（未开始/作答中/已交卷）、班级均分与学生状态列表。
6. **题库共享与按规则随机抽题（每人一卷）**：question_bank_items.visibility 支持私有/同实例共享（共享不复制条目）；assessments.settings_json.draw 按类型/标签/难度抽题，种子 assignmentId:studentKey:attemptNo 确定性洗牌并持久化 paper_json；同一学生重入集合与顺序不变，不同学生卷面不同；可用题不足抛 409 不静默少题。修复了抽题 PRNG 种子哈希雪崩不足问题（相邻 attempt 卷面碰撞率 1.63% → 0.89%，回归理论值）。
7. **难度/区分度项分析与导出**：新增纯函数项分析（区分度采用题目得分与剩余卷面分的 Pearson 相关，避免 part-whole 虚高）；样本不足/全对全错/方差为 0 时退化为 null 不输出 NaN；待人工批改不计入；CSV（带 BOM）/JSON/XLSX 三种导出。
8. **AI 辅助批改建议（教师确认后生效）**：主观题可请求 AI 建议（建议分/理由/置信度），只写建议列不改分；教师确认后走既有批改路径并记审计；单次 15s 超时、每操作者 60s 20 次限流；Provider 缺失/超时/非法输出均明确报错且不阻塞人工批改。
9. **存量数据迁移**：新增 CLI（支持 --dry-run）把白板 quiz 图元与带正确答案的预置投票转为新测评模型；幂等（legacy.sourceId 标记）、只读旧表、纯投票与非法数据跳过并报告原因。
10. **插件题型生态开放**：插件可注册题型（判分/出题/作答 UI 全链路），自带 getAiGradingPrompt 自定义 AI 批改提示词；试卷支持 JSON/CSV/XLSX 导出与导入（题型未安装时明确报错并给出缺失清单，而非静默丢题）；新增三个扩展槽位（列表卡片/作答工具条/统计卡片），props 经白名单收敛不含答案与学生身份。

## 二、安全与信任边界体系化加固

1. **插件签名校验与分发安全**：社区插件 Ed25519 签名与流式哈希完整性校验；安装来源分级；未受信任插件强制独立子进程隔离（不继承密钥类环境变量）；auth: false 不再等于匿名可访问（须管理员显式批准公开路由）；install-from-url 下载前要求 acknowledgeRisk。
2. **路由越权与数据范围系统性修复**：GET /api/lessons 与单条端点按角色收窄（管理员全量/教师自己教的/学生自己班的，先判存在性再判可见性）；课件作答记录按教师所教班级切片；presence 更新仅投递教师/管理员房间；VFS 与文件下载限教师/管理员；白板读接口按角色脱敏并校验归属；班级/作业/提交/成绩按角色与班级成员授权（作业 JSON 对学生隐藏答案）。
3. **对象级授权与存储安全**：学生写操作与私有备忘 IDOR 修复；私有备忘存储型 XSS 净化；学生花名册按归属过滤；学生登录拒绝明文口令且失败文案不暴露账号存在性；班级临时口令与 AI Provider API Key 加密存储；未设 ENCRYPTION_KEY 时不再使用临时内存密钥。
4. **传输与进程边界**：生产 CORS 只接受显式 ALLOWED_ORIGINS；生产环境拒绝 PLAYWRIGHT_TEST；启动期环境变量强校验（非法取值直接拒绝启动，生产环境种子口令设为用户名也拒绝）；插件网络代理私有地址/元数据/DNS 重绑定防护；课件嵌入默认收紧同源；桥接 SDK 出站消息不再静默广播到 *；AI 对话/批改/课表不跟随未复检的重定向。
5. **多轮审计整改闭环**：SQL 守卫嵌套子查询与括号表名防御、会话归档/删除状态同步、课堂简报真实聚合、Worker RPC 保活、班级删除级联、SocketService 重连保活、插件沙箱熔断、看板搜索竞态取消、倒计时定时器清理、课节级联删除覆盖插件提交等 Critical/High/Medium 项全部闭环并入库审计报告。
6. **依赖与类型门禁**：依赖审计清零（pnpm-workspace overrides 精确替换已修补版本，CI 对 high+ 失败即红）；14 处严格类型诊断修复并将 strict / noImplicitAny / strictNullChecks 并入主 tsconfig。

## 三、插件生态能力扩展

1. **插件配置分层（平台 → 学校 → 班级）**：新 plugin_config 表与迁移；解析顺序 班级 > 学校 > 平台 > manifest 默认值；manifest 声明可覆盖层级（缺省仅平台，老插件行为不变）；迁移未执行时回退读旧位置。
2. **宿主与插件统一命名空间 i18n**：manifest contributes.locales 支持内联字典与 JSON 文件两种形态；声明式 UI %key% 国际化；Zod 校验、注册索引与生命周期回收。
3. **声明式版本化迁移与卸载数据语义**：插件可声明迁移并在失败时事务回滚、降级保护；卸载默认保留数据、清除前先导出、重装自动复用；待审批指令生命周期管理（保留策略、卸载级联清理、审批失效容错）。
4. **扩展点生命周期与弃用策略**：弃用规范与插件升级兼容性预检报告；停用/卸载时已挂载扩展统一清理。
5. **按插件维度可观测性**：命令派发、事件发布、插件 REST 网关与 Worker 生命周期按插件累计计数与耗时，/metrics 追加 openlearn_plugin_* 系列；标签转义与截断、溢出条目落 **overflow**，指标记录失败不影响业务。
6. **扩展插槽大批量扩充**：备课时间线节点徽章、学生环节步骤徽章、顶栏后台任务项、课表导入源与条目动作、课堂活跃环节主交互区、学生学年对比指标卡、作业批改工具条/条目附加/量规附加、学生环节门禁回退、备课环节形态配置、测评三槽位、机房排座三槽位、互评作品预览、课程向导 Quick Apply 等；props 白名单与 manifest schema 同步扩充。

## 四、课堂互动体验深化

1. **答题锁定与专注锁定解耦（Issue #110）**：新增 navigation（答题锁定）模式——限制导航但完全放开白板作答与作业提交；教师端分体按钮组一键切换模式，学生监控圆环与学情卡片按模式区分视觉；学生档案桥接修复锁定徽章不显现的边界问题。
2. **互动课堂进入方式重构（Issue #91）**：进入 live_class 先看「进行中的课堂会话」列表（阶段徽标、已用时长、在场学生数），可继续上课/归档/开新课；刷新与切标签页回来经 sessionStorage 记忆直接回授课视图。
3. **课堂会话与档案管理看板**：会话列表（分页/筛选/搜索/指标聚合）、一键归档释放班级、安全删除（事务级联清理投票/选票/抢答/通票/弹幕/互评/动态流）；跨教师越权防护。
4. **学生端返回课堂入口（Issue #109）**：看板顶部横幅一键回到真实进行中的课节；学生身份强制使用会话内 studentId，忽略越权参数。
5. **专注力监控点击固定（Issue #115）**：学生卡片可锁定选中持久查看详情，支持临时悬浮预览、键盘操作与 Esc 取消。
6. **大屏作业互评赏析（Issue #95）**：跨来源作品池统一聚合（课堂作业/课件作答/传统作业）、焦点对比多模态预览（图片/附件/文本/代码高亮）、全班作品池抽屉自由对焦、顶栏快捷入口。
7. **课表与机房效率**：课表页「快速开始上这节课」一键开课；课表 AI 识别升级为全局后台任务（页面可自由跳转、顶栏状态、完成 Toast 直达、草稿现场持久化与刷新恢复）；机房座位 HTML5 拖拽调座与交换。
8. **一批课堂细节修复**：教学蓝图环节时长不再显示 NaN；随堂倒计时定时器清理与状态隔离；随机点名只抽取已进入本节课的学生；进行中的会话不能换班；课堂情绪追踪与优秀学员实时通道死链修复。

## 六、质量基础设施与自动化门禁

1. **全角色功能巡检 pnpm sweep（Issue #198/#208）**：API 登录态注入浏览器、导航项运行时发现、5 轮角色巡检（管理员→学生→学生课中→教师→教师授课中）、只读不写；全局问题与视图问题分离；产物报告可直接贴 issue。已接入 CI（feature-sweep job，未捕获异常/导航失败/任何 4xx·5xx 即阻断）。
2. **写流程剧本机制**：业务写入走 API + 观察走浏览器；首个剧本覆盖作业闭环（发布→提交→批改 88→查成绩→回看，含 API 断言）。
3. **「上一正式版 → main」升级回归门禁（Issue #147）**：以 release tag 起真实进程装插件造数据生成 fixture，恢复后用当前 main 启动断言插件 active、旧数据可读、迁移 checksum 未改写、零新迁移；反向验证门禁本身有效。
4. **测试库与开发库物理隔离（Issue #194）**：Vitest 按 worker 使用独立临时 SQLite 库，杜绝自动化测试污染工作区数据库。
5. **无障碍与对比度门禁**：登录页 + 教师端 8 工作区 + 学生仪表盘/作业面板 + 学生课中与互动浮层的 axe-core 全规则集零违规断言入 CI；四套主题 WCAG 对比度令牌回归（正文与填充主色白字均 ≥ 4.5:1）。
6. **巡检真实缺陷修复**：学生锁定状态从未生效（GET /api/students 对学生放行且只返回自己一条）、互动课堂无会话时 view-state 稳定 404、学生端 DB 徽章与 5s 心跳越权、学生端默认选中他人课节导致白板 403。

## 七、可观测性、运维与部署

1. **健康检查与指标**：/health（进程存活）、/health/ready（数据库/存储/迁移，失败 503 不泄露内部细节）、/metrics（Prometheus 文本，默认仅管理员或 METRICS_TOKEN）；新增迁移积压、备份年龄、events 行数三条 gauge（进程内缓存 15s）。
2. **日志与审计**：http.request 带请求 ID/用户 ID/耗时/状态码；登录失败、限流、越权、插件安装启用、公开路由批准写入 audit.log；访问日志静态资源与探活静默、按大小轮转；未捕获异常/路由 5xx/浏览器运行时错误结构化日志，可配 SENTRY_DSN 转发（脱敏，不含口令/会话/学生作答）。
3. **迁移失败快照恢复与 CI 演练**：restore 先做完整性与迁移兼容性预检，VACUUM INTO 生成安全副本后原子替换；新增演练作业（建库→注入失败迁移断言回滚→快照恢复→真实服务启动验证）。
4. **部署链路**：Docker 数据目录 /data 与 /backups；PM2 透传 TRUST_PROXY/种子口令/数据目录；生产镜像按文档从零构建、保留 esbuild、插件目录跟数据卷走；CI pnpm 固定 packageManager 版本。
5. **公测准备**：公测旅程 E2E（强制改密→建班布置→学生提交→批改→跨班拒绝→插件安装启用）、错误监控、已知问题与运营材料入库。

## 八、破坏性变更与迁移注意

1. **第三方插件默认子进程隔离**：manifest id 非 @openlearn/ 且未列入 OPENLEARN_TRUSTED_INLINE_PLUGINS 的插件，安装/更新/激活/启动恢复时一律改写为 executionMode=process；需要进程内运行的自研插件须显式加白。
2. **插件公开路由须显式批准**：auth: false 仅表示申请公开，匿名放行还须管理员批准 METHOD + path；升级后原先依赖 auth: false 的匿名接口将返回 401。
3. **总线事件表默认只保留 90 天**：events 不再无限增长（启动时按 timestamp 清理）。
4. **生产环境跨域只认 ALLOWED_ORIGINS**：未配置显式来源时不再回落宽松策略。
5. **迁移前快照失败会阻止启动；比当前构建更新的数据库不再被视为就绪**：从 v0.6.1 升级时同样适用。
6. **明文学生口令不能再登录；GDPR 删除只保留给管理员**；/health/ready 与 /metrics 响应合同收紧。
7. **Docker 数据目录改为 /data 与 /backups**：既有部署需更新卷挂载与环境变量。

# Release Notes v0.3.8

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.8** 是一次针对**命令行运维能力与开箱即用体验的全景增强（Comprehensive CLI & Operations Suite）**。本版本系统性地为 `npx openlearn-next` 打造了集**环境体检自检、在线数据冷备、安全还原回滚、免界面管理运维、局域网多网卡直显、一次性隔离沙盒演示与零依赖浏览器自动打开**于一体的完整命令行工具链。

---

## 核心新特性

### 1. 局域网 IP 自动侦测与终端直显 (`-H, --host`)
- **多网卡智能扫描**：启动时自动扫描并解析本机所有活跃的物理与虚拟网卡 IPv4 地址；
- **终端多端直显**：同时以高亮及 OSC 8 可点击链接形式输出 `Local` (http://localhost:PORT) 与 `Network` (http://192.168.x.x:PORT) 地址，彻底解决课堂与机房教学多设备联调痛点；
- **主机绑定支持**：支持 `-H, --host <ip>` 参数自定义监听接口（默认 `0.0.0.0` 全网监听）。

### 2. 服务就绪后自动唤起浏览器 (`-o, --open`)
- **跨平台零外部依赖**：基于原生 Node.js `child_process.spawn`，在 macOS (`open`)、Windows (`cmd start`) 和 Linux (`xdg-open`) 上统一支持；
- **精准时机**：在 HTTP 服务器真正绑定端口并输出就绪信息后静默打开默认浏览器，消除白屏竞争。

### 3. 系统环境健康自检与就绪诊断 (`doctor`)
- **执行命令**：`npx openlearn-next doctor`
- **五维全自动体检**：
  1. **Node.js 运行时**：严格校验 Node >= 20.0.0；
  2. **硬件架构与内存余量**：探测 CPU 核心数、系统总物理内存与当前可用剩余内存（<256MB 智能预警）；
  3. **数据存储读写权限**：自动探测数据存储目录并进行原子读写及删除校验；
  4. **端口状态探测**：检测目标端口（默认 9000 或 `-p` 指定）是否被其他程序占用；
  5. **局域网接入点**：侦测当前宿主机网络可用性。

### 4. 在线数据一致性冷备快照 (`backup`)
- **执行命令**：`npx openlearn-next backup [output.db]`
- **实时一致性导出**：基于 SQLite WAL 机制在线备份，无需停止正在运行的服务，毫秒级导出 100% 数据一致的快照副本；
- **自动时间戳命名**：缺省输出文件名自动带入年月日时分秒（如 `openlearn_backup_20260906_132847.db`）。

### 5. 坏文件防护与安全回滚还原 (`restore`)
- **执行命令**：`npx openlearn-next restore <backup.db>`
- **Magic Header 校验门禁**：还原前严格校验文件头是否为标准 `SQLite format 3\0`，杜绝非法注入与坏文件损坏数据库；
- **自动生成回滚镜像**：覆盖当前主库前，自动为老数据创建带有时间戳的 `.bak_<timestamp>` 安全备份；
- **状态重置**：还原后自动清理旧的 WAL 与 SHM 文件，确保主库立即进入整洁可用状态。

### 6. 终端免界面重置管理员密码 (`reset-admin`)
- **执行命令**：`npx openlearn-next reset-admin [--password <new_pwd>]`
- **bcrypt 密码加密**：直接在终端将管理员 `admin` 密码安全哈希写入主库；
- **智能账号兜底**：若数据库为空或缺少管理员账号，自动补全具备 `administrator` 权限的 `admin` 账号。

### 7. 终端插件状态速查 (`plugins [list]`)
- **执行命令**：`npx openlearn-next plugins`
- **ASCII 美化表格**：终端直显当前安装的所有插件 ID、版本（动态从 manifest 解析）、激活状态及运行模式（`esm` / `vm` / `inline`），并具备全版本数据库 Schema 自适应容错能力。

### 8. 一次性纯净临时沙盒演示模式 (`--demo` / `--temp`)
- **执行命令**：`npx openlearn-next --demo`
- **临时数据隔离**：在系统临时目录 `/tmp/openlearn-demo-*` 建立独立数据库；
- **退出自动销毁**：通过进程信号优雅转发（`SIGINT` / `SIGTERM` / `exit`），在退出时自动彻底销毁沙盒数据，不留任何本地残留，最适合公开课展示、培训与临时调试。

### 9. 跨域白名单命令行透传 (`--cors <origins>`)
- **执行命令**：`npx openlearn-next --cors "http://localhost:5173,*"`
- **全链路贯通**：参数自动注入 `ALLOWED_ORIGINS` 环境变量，Express 与 Socket.IO 实时网关同步生效。

## 常用命令速查 (CLI Cheat Sheet)

```bash
# 1. 运行系统体检自检
npx openlearn-next doctor

# 2. 启动服务并自动在浏览器打开
npx openlearn-next -o

# 3. 指定端口与跨域白名单
npx openlearn-next -p 8080 --cors "http://localhost:5173,*"

# 4. 纯净临时沙盒演示（用完退出自动删除临时数据）
npx openlearn-next --demo -o

# 5. 查看已安装插件清单
npx openlearn-next plugins

# 6. 一键在线备份数据库
npx openlearn-next backup my_backup.db

# 7. 从备份还原数据（自动备份旧库以供回滚）
npx openlearn-next restore my_backup.db

# 8. 免界面重置管理员密码
npx openlearn-next reset-admin --password new_password_123

# 9. 清理 NPX 包缓存
npx openlearn-next clean --npx
```

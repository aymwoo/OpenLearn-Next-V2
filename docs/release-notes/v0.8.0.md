# Release Notes v0.8.0

**发布日期**: 2026-11-25

v0.8.0 是 0.7.17 之后的次版本发布，聚合教学模式基座、LearningSurface、学案活动、课堂流程扩展、学生首屏与 Dialog 视觉体系等一批能力。本版本包含少量需要关注的接口与配置口径变更，见文末「升级注意」。

## Highlights

- **教学模式基座（Mode Pack）**：`mode.pack` 契约从 P0 推进到 P4，支持第三方交付引擎接管备课面、课中工作区、大纲与成绩采集；内置白板包与学案包可双端挂载，课程向导按目录渲染交付模式。
- **LearningSurface 统一教学内容容器**：状态底座、attempt 会话、内置渲染器（演示文稿 / 作业 / HTML 课件）与插件沙箱渲染器落地；白板 `html-applet` 存量原地迁移为 `learning_surface`，作业提交统一补 `attempt_id`。
- **学案活动体系**：新增阅读、作品提交、测验、调查、填表、讨论六类内置活动；教师批阅后可显式同步到成绩册，并补齐重复成绩项、学年口径与课节完成度判定。
- **课堂流程扩展基座**：可靠课堂消息协议、学分与奖励兑换、SubmissionAdapter 成绩采集、双端授课工作区槽位，支撑「不用白板」的第三方教学模式。
- **Dialog 统一视觉系统**：新增 `--ol-dialog-*` 设计令牌与 `.ol-dialog-*` 结构类，四套内置主题自动跟随，第三方主题包可覆盖；全站系统弹窗与插件宿主确认框统一迁移。

## Features

- **第三方模式包与课程交付**：`GET /api/mode-packs` 返回内置与已激活插件包；课时新增 `mode_pack_id`；包不可用时回落内置白板并记录 `modeBinding.reason`。新增 `classroom.prep` / `classroom.outline` 扩展槽，第三方可接管备课面与课中大纲。
- **LearningSurface**：新增 `learning_surfaces` / `learning_surface_attempts` 与 `/api/learning-surfaces/*`；`CoursewareHost` 独立课件容器、`courseware.host` 扩展槽、学案「互动课件」区块与课程包 v2 导入导出。
- **学案与成绩**：新增 `POST /api/lesson-activities/:id/sync-grade` 等同步端点与教师进度面板批量同步；学期总评按学年过滤、按成绩项键去重；补录成绩按课节真实关联课件收敛；课节完成度改为全部关联课件完成才置 100%。
- **课堂体验**：互动课堂统一从起始门户进入；归档结束回到门户；课堂工具合并为统一入口并新增「控制」页；白板课顶栏精简、倒计时移入工具栏；学生专注监控可折叠；学生首屏新增「现在该做什么」学习路径条。
- **活动协议收敛**：新增 `/api/activity-providers`、`/api/activity-runs` canonical 路由与统一 `activity.completed` 事件；旧 `/api/activities*` 保留为 307 兼容别名。
- **插件安全扩展服务**：新增 `assignmentSubmission`、`xueanActivityProgress`、`lessonReport`、`classroomSelfMessage` 宿主只读/受限写入服务与 `assignment.submission.actions` 槽位。
- **Dialog 体系**：`AccessibleDialog` 新增 `DialogHeader / DialogTitle / DialogCloseButton / DialogBody / DialogFooter / DialogSection / DialogButton` 原语与稳定 `data-dialog-*` 钩子；迁移全部系统弹窗、插件宿主确认框、课表弹窗、学生破冰、帮助向导与附件预览。
- **运维与工程**：仓库协作切换为 Gitee 单平台；版本号旁展示当前 commit 短哈希；新增历史重复成绩只读体检脚本 `pnpm db:report-duplicate-grades`。

## Fixes

- 修复学期作业分被其他学年作业拖低、同一成绩被多条 assignment 重复计分、课堂选人分层与课后报告统计口径不一致。
- 修复白板课中大纲多页展示错误、中栏停留在空环节工作区、按环节删除页面误删其他环节同序号页。
- 修复学生端点击「全屏」无反应，以及离开课节后残留全屏 + 折叠状态导致整页空白。
- 修复 `classroomSelfMessage` 空数组目标被降级为广播、作业提交只读服务漏读作业中心表、学案活动进度未过滤可见性等边界问题。
- 修复第三方课件/模式包未激活时开课白屏，统一自动回退白板。

## 升级注意

- `GET /api/assignments*` 读端点与旧作业写端点已下线为 `410`，请迁移到 `/api/learning-surface-assignments/*`；`/api/activities*` 仅保留 307 兼容别名。
- Mode Pack、学生平行学案页、社区安装、课件遥测、HTTP 访问日志与未签名本地插件策略改由管理后台「站点信息设置 → 运行时策略」管理；对应的 `VITE_OPENLEARN_MODE_PACKS`、`window.__OPENLEARN_*` 与 `OPENLEARN_*` / `BRIDGE_HOOK_TELEMETRY` / `HTTP_ACCESS_LOG*` 环境变量不再控制这些功能。
- 主题兼容基线 `DEFAULT_PLATFORM_VERSION` 提升到 `0.8.0`；第三方主题若声明更宽的兼容范围无需改动。

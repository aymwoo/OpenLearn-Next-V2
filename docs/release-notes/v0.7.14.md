# Release Notes v0.7.14

**发布日期**: 2026-11-08

v0.7.14 是白板/互动课堂的首帧与切页稳定性修复版本，不包含数据库迁移与 SDK 变更。

## 修复

- **白板首帧与切页闪动**：`InteractiveWhiteboard` 在状态初始化阶段同步解析 `page_meta`，传入 `activeSegmentId` / `initialPage` 时首帧直接命中目标页，消除「先渲染第 0 页再跳页」的瞬移。
- **环节联动切页加引用守卫**：只有教师真正切换不同环节时才自动切页，同一环节内手动翻页不再被弹回。
- **尺寸保活**：Keep-Alive 后台 `display:none` 测出 `0×0` 时保留有效宽高，切回课堂不再二次拉伸。
- **首帧挂载**：教师从工作台切到互动课堂时同步渲染容器，消除 1 帧空白。
- **回调引用稳定**：`onPagesStateChange` 统一 `useCallback`，阻断父子组件无效重渲染级联。

## 验证

- 全量 Vitest 通过；教师端进入白板、切换环节、从其他 Tab 切回课堂的手工回归通过。

# Release Notes v0.6.1

**发布日期**: 2026年10月13日

OpenLearn V2 **v0.6.1** 是平台的**系统韧性加固与课堂端到端闭环质量补丁版本 (Classroom Resilience & Full Lifecycle E2E Quality Patch)**。本版本交付了覆盖率达 100% 的师生双端课堂教学全生命周期自动化测试套件，彻底完成了班级/学生批量导入链路的全字段识别与单实现收敛，重构落地了 40 分钟标准课时框架向导与基于 AI Provider 的真实教学大纲生成流水线，系统性修复了课堂阶段流转保持、白板分页元数据拦截及无障碍交互规范缺陷，并完成了后台上传大小动态配置与插件治理债务的全面闭环。

---

## 一、课堂教学全生命周期 E2E 自动化测试矩阵 (100% 流程闭环)

针对过去测试碎片化、依赖直接 API 触发及缺少双端一镜到底等薄弱点，本版本设计并交付了三大高价值 Playwright E2E 自动化测试套件：

1. **师生双端全生命周期黄金主干旅程 (`e2e/classroom-golden-journey.spec.ts`)**：
   - 跨两个独立浏览器上下文真实模拟教师端与学生端；
   - 完整闭环串联：开课就绪 (`PRE_CLASS_READY`) → 推进上课与限时倒计时 → 教师极速投票与学生作答实时计票 → 学生发送节奏晴雨表信号 → 推进至课后小结 (`WRAP_UP_EXIT_TICKET`) → 60s 自适应通票作答提交 → 教师端词云动态刷新与知识树点亮 → 教师填写反思备忘录 → 推进至全景简报 (`ARCHIVED_REPORT`) 查看 4 大 KPI → 双向平滑回退至课中白板。
2. **教师端中控与白板多环节操控 (`e2e/classroom-teacher-cockpit.spec.ts`)**：
   - 教学步骤时间轴切换（环节 1 → 环节 2）；
   - 白板多页大纲控制（新建 P2、翻页、大纲折叠收起与展开）；
   - 教师视野伸缩（收起/展开左侧教学步骤边栏）；
   - 教师中控工具箱唤出（抢答器激活/重置、随机抽人弹窗、班级积分榜）。
3. **意外刷新容灾与四大高级教学模态框 (`e2e/classroom-resilience-and-modals.spec.ts`)**：
   - 课中误触 `F5` 刷新后自动恢复至 `IN_CLASS_TEACHING` 现场、当前步骤及白板页码；
   - 逐一验证学生五维雷达档案 (`StudentGrowthProfileModal`)、AI 学情预测 (`MasteryPredictionModal`)、异常告警中心 (`DiagnosticCenterModal`) 与家校通知生成器 (`ParentNotificationModal`)。
4. **性能与隔离**：三大套件 28 秒全绿回归，严格保证测试前后数据库 0 脏数据残留，全流程自动沉淀高清工件截图至 `artifacts/screenshots/`。

## 二、班级与学生批量导入链路全字段支持与单实现收敛

修复了批量导入中长期存在的字段丢失与三端行为互斥问题：

1. **全字段识别与透传**：在 `bulkImportService.ts` 补齐学号 (`student_number`)、初始密码 (`password`)、学生备注 (`private_notes`) 的提取支持，彻底终结此前教师填写的学号被静默丢弃的问题。
2. **三端入库单实现收敛**：废除 `/api/classes/import`、`/api/students/import` 与 `bulk-enroll` 三份割裂的实现，统一收敛至 `RosterService.importStudents()`。
3. **去重与密码安全策略**：去重键拓展为 `email` → `student_number`，命中已有学生跳过创建且不覆盖原有密码；缺失密码时自动生成 12 位高强度初始密码并在成功提示中一次性回传清单，方便教师打印分发。
4. **复杂 CSV 解析增强**：改写为逐字符状态机，完美支持逗号引号嵌套与 `""` 转义；表头匹配采用规范化精确匹配加长度降序包含匹配的双级策略。
5. **性能优化**：将 bcrypt(cost=10) 密码哈希计算移出 SQLite 事务，避免 50 人班级导入按住写锁 3~5 秒。

## 三、课程发布向导：统一 40 分钟框架与真实 AI 大纲生成

1. **统一 40 分钟标准课时**：
   - 三个课堂框架模板（经典讲授 `5-15-15-5`、主题讨论 `5-13-12-10`、翻转训练 `8-14-13-5`）由 45 分钟统一规范为 40 分钟；
   - 初始默认时间轴与各学科专家建议文案全线对齐 40 分钟。
2. **真实 AI Provider 大纲生成**：
   - 彻底废除前端硬编码假大纲模板，清理 `helpUtils2.ts` 死代码；
   - 新增 `POST /api/lessons/generate-outline` 端点与限流保护，基于内核 `AIService` 与配置的真实大纲模型，结合课题、学科分类、简介及时间轴生成结构严密的 Markdown 教学大纲；
   - 客户端配备生成中 loading 态与安全回退，自动剥离外层代码围栏。

## 四、课堂全生命周期流转保持与白板元数据放行

1. **白板分页元数据放行**：在 `packages/plugins/builtin.ts` 的 `KNOWN_ELEMENT_TYPES` 中补齐 `'page_meta'`，修复教师新建白板页时 `whiteboard.draw` 抛出 500 错误的严重隐患。
2. **结课阶段会话保持与双向回退**：修复查询 session 排除 `ARCHIVED_REPORT` 导致误判会话丢失强制回退的缺陷，允许结课简报合法流转回课中授课。
3. **结课通票实时闭环**：教师端实时监听 `classroom:exit_ticket_submitted` Socket 事件，学生交卷实时刷新词云与知识树。
4. **模态框可访问性规范**：为全仓 6 个关键教学弹窗规范 `role="dialog"` 与 `aria-label="Close"`。

## 五、内核治理与生态优化收尾

1. **课件上传上限动态可配置**：管理后台站点设置新增「上传大小上限 (MB)」配置项，新增 `020_upload_max_file_mb.sql` 迁移，前端课件上传动态按配置校验。
2. **国家智慧教育公共服务平台连接器清退**：响应用户决策，整体清退未开放第三方网关的 `@openlearn/plugin-smart-edu` 及其关联代码，保持扩展槽位等通用机制完好。
3. **插件系统健壮性加固**：完善通用声明式 `contributes` 桥接，封堵 actor 伪造提权风险，重构插件熔断状态机与恢复路径，合并 SDK 门禁管线。

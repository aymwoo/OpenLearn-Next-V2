# Release Notes v0.3.11

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.11** 带来了全新的**插件系统安全 RESTful API 与纵深防御网关体系（Plugin RESTful API & Security Gateway）**。本版本为插件生态提供标准的 HTTP/RESTful 通信能力，并贯穿主线程与 Worker 沙箱隔离层，建立了覆盖认证、细粒度 RBAC 权限控制、路径遍历防御、请求体硬限制、滑动窗口限流以及响应头脱敏清洗的六道纵深安全防线。

---

## 核心新特性与安全架构

### 1. 声明与注册双轨架构 (Declarative & Imperative Routing)
* **Manifest 静态审计声明**：
  在 `manifest.json` 中支持通过 `api.routes` 静态声明路由规则，使平台运维与静态安全审计工具能在插件启动前识别端点清单及安全策略：
  ```json
  "api": {
    "routes": [
      { "method": "GET", "path": "/public-status", "auth": false },
      { "method": "POST", "path": "/grades/:id", "auth": true, "roles": ["teacher", "administrator"], "rateLimit": { "max": 60, "windowMs": 60000 } }
    ]
  }
  ```
* **插件动态路由定义 (`PluginHttpRouter`)**：
  插件在 `activate(ctx)` 生命周期中直接使用 `ctx.http` 注册路由处理函数（支持 `get/post/put/delete/patch/all`），自动提取动态路径参数（`:param`）与通配符，并自动将普通返回对象包装为标准响应。
* **生命周期与资源清理**：
  路由器实例与 `ResourceTracker` 深度绑定，插件停用、卸载或热重载时自动注销清理端点，杜绝内存与路由泄漏。

### 2. 统一安全网关中间件 (`PluginApiGateway`)
所有插件 RESTful 流量统一挂载至 `/api/plugins/:pluginId/*`，并在主线程网关前置执行六道防御：
1. **系统保留端点避让**：精准避让 `config`、`toggle`、`contributions` 等系统管理操作，保证向后无缝兼容。
2. **路径遍历防护 (Path Traversal Protection)**：对原始与规范化子路径执行双重 `..` 与 `%2e%2e` 检测，阻断潜在的文件读取与越权攻击（返回 `400 Bad Request`）。
3. **Payload 体积硬限制 (DoS/OOM 防护)**：请求体大小上限设为 **1MB**，防止恶意大报文打爆主线程或 Worker 线程内存（返回 `413 Payload Too Large`）；大文件必须走平台统一 `IStorageService`。
4. **IP + 插件级内存滑动窗口限流器 (Rate Limiter)**：单端点默认 120 req/min，超出限制自动返回 `429 Too Many Requests` 与 `Retry-After` 标头。
5. **前置认证与 RBAC 权限守卫**：解析 Cookie 会话（`edu_os_token`）与 Bearer Token；未认证返回 `401 Unauthorized`，角色权限不符返回 `403 Forbidden`；仅对显式声明 `auth: false` 的公开路由放行。
6. **响应头安全脱敏清洗**：出站前强制剥离 `Set-Cookie`、`Content-Security-Policy`、`Access-Control-Allow-Origin` 等高危标头，杜绝插件篡改主域会话或降低安全策略。

### 3. Worker 沙箱隔离模式跨线程 RPC 通信
* **跨线程 DTO 序列化隔离**：
  主进程与 Worker 线程之间通过 `httpRequest` 与 `httpResponse` 协议传输纯只读 `PluginApiRequest` DTO。Worker 内运行的沙箱插件完全无法接触到 Node.js 原生 Express `req` / `res` 实例。
* **5000ms 超时熔断保护**：
  请求派发至 Worker 线程设有看门狗超时机制，5000ms 未响应即自动熔断并向客户端返回 `504 Gateway Timeout`，保障主服务的高可用。

### 4. 开发者测试套件联动 (`@openlearn/plugin-test-kit`)
* `@openlearn/plugin-test-kit` 的 `createMockContext()` 现默认内置 `PluginHttpRouter`，让第三方插件开发者无需启动真实平台即可对自己的 RESTful API 进行完备的单元与集成测试。

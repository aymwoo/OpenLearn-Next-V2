# Release Notes v0.3.1

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.1** 是 v0.3.0 主题系统大版本后的**安全硬化补丁**。本版本集中落地 4 轮安全治理（Round 1–4），覆盖路由鉴权、Socket.IO 握手、CSP 收紧、LMS Bridge 定向化、IDOR/课程所有权、白板写权限等 14+ 个 VULN 修复，配套新增插件导航 API `setSelectedLesson`，全平台 177 测试套件 / 1011 用例持续 100% 绿灯，`pnpm audit --prod` **0 vulnerabilities**。

---

## 主要更新

### 1. 插件导航 API 扩展
- `FrontendPluginContext.navigation` 新增 `setSelectedLesson(lessonId: string | null)` 方法，转发到 `appStore.setSelectedLesson`，供第三方插件在 `activate(ctx)` 中切换当前课节。

### 2. 安全 Round 4：IDOR 课程水平越权防护与教师专属所有权
- **数据层升级**：`lessons` 表增加 `creator_id TEXT` 字段，平滑迁移历史老版本课程。
- **内核指令绑定**：`lesson.create` 自动解析创建人 ID 并写入领域事件。
- **路由所有权守卫与白板写权限中间件**：
  - `checkLessonOwnership(req, lessonId)` + `requireWhiteboardWriteAccess()` 声明式中间件
  - 课堂主白板强制教师/管理员验证所有权；随堂作业白板强制身份与作业拥有者校验
  - 挂载至 5 个白板写路由 + quiz-submit / quiz-submissions / ai-tutor
- **教研协同流转与一键克隆**：`POST /api/lessons/:id/clone` 强制鉴权并自动归属流转
- **前端交互与安全视觉**：CourseManagement 皇冠徽章 / 只读图标 + 禁用删除；LessonEditorView 只读横幅与一键克隆引导

### 3. 安全 Round 3：工程治理与传输安全
- **SEC-01** Cookie `edu_os_token` 安全属性（动态 Secure / 7 天对齐）+ Nginx HTTPS 443 TLS 1.2/1.3 模板
- **SEC-02** `/metrics` / `/api/ai-providers` / `/api/admin/logs` 鉴权 + 统一 `sendSafeError` 脱敏中间件
- **SEC-03** 清理 `package-lock.json` / `temp_check.mjs` / `test-results/`，补 `engines` 字段，重构 `db:backup`
- **SEC-04** 清理路由拆分遗留无用导入与全量解构，ESLint 警告缩减近 600 个
- **SEC-05** 校正 AGENTS.md 关于 Vitest `fileParallelism` 的文档失真

### 4. 安全 Round 1–2：14+ VULN 修复
- **VULN-01** 6 个核心业务路由（roster / grading / assignments / schedules / lessons / workspace）补齐 `requireAuth`；`/api/vfs` 数据脱敏
- **VULN-02** 课件成绩冒名拦截（按 attempt 所属 student_id 强校验）
- **VULN-03** 审批端点强制 `administrator` 鉴权 + 彻底移除 `payloadOverride` 字段
- **VULN-04** 插件安装 `--ignore-scripts` + `ALLOW_UNSAFE_PLUGIN_SCRIPTS` 环境变量门禁 + 默认凭证日志预警
- **VULN-05** Worker 资源配额 `maxOldGenerationSizeMb: 128 / maxYoungGenerationSizeMb: 32`
- **VULN-06** MathGraph `eval` → 自研 AST `safeEvaluateMath`；CodeSandbox 代码执行迁移至 Worker Blob + 3s 看门狗
- **VULN-07** 课件上传 `path.basename` 净化 + `!destPath.startsWith(storageDir)` 沙箱边界；HTML 资源响应头注入 `CSP: sandbox` 降级为 opaque origin
- **VULN-08** Socket.IO `io.use()` 握手鉴权 + CORS 严格白名单（生产禁止 `origin: '*'`）；`teacher-broadcast-segment` 等教师专属事件强校验
- **VULN-09** 插件 ZIP Zip Slip 防御：`path.resolve` 强校验必须以安装目录为前缀
- **VULN-10** Helmet CSP 收紧：`scriptSrc` / `frameSrc` 移除 `https:` / `data:` 通配，仅保留 `'self'` + `blob:` + 受信域
- **VULN-11** DB RPC `FORBIDDEN_OPERATIONS` 正则拦截 `ATTACH / DETACH / PRAGMA / VACUUM / CREATE|DROP TRIGGER|VIEW`
- **VULN-12** 依赖治理：`xlsx` / `vite` → devDependencies；`pnpm-workspace.yaml` overrides 升级 `ws` / `socket.io-parser` / `nanoid` / `postcss` / `ip-address` / `dompurify` / `qs` / `body-parser` / `protobufjs` 至安全版本
- **VULN-13** LMS Bridge 定向回传：消息接收方校验 + `event.origin` 真实域名解析
- **VULN-14** 插件解析去 `new Function` 改纯静态正则；插件静态路由响应头注入 `CSP: sandbox` + `X-Content-Type-Options: nosniff`

# Release Notes v0.3.2

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.2** 是针对生产分发与 CLI 独立运行模式（`npx openlearn-next@latest`）的关键**依赖解耦与启动稳健性修复补丁**。本版本彻底消除了构建产物中的外部开发期模块提升引用，解耦了 Vite 与 esbuild 在服务初始化阶段的同步依赖，确保零 `devDependencies` 安装场景下开箱即用。

---

## 主要更新

### 1. Vite 开发期依赖按需动态加载 (Vite Decoupling)
- **根因消除**：在 `server.ts` 中移除顶层静态 `import { createServer as createViteServer } from 'vite'`。此前 esbuild 以 `--packages=external` 打包 CommonJS 产物时，将静态 import 提升为 `dist/server.cjs` 顶层的 `require("vite")`，导致在生产环境（仅包含 `dependencies`）通过 `npx` 启动时直接崩溃。
- **按需加载**：将 Vite 中间件加载逻辑置于 `process.env.NODE_ENV !== 'production'` 分支内，改用原生动态异步 `await import('vite')`，确保生产运行时永远不会解析或要求 `vite` 模块。

### 2. esbuild 核心解耦与生产依赖补全 (esbuild Runtime Hardening)
- **次级隐患消除**：在 `packages/core/esm-loader/install-utils.ts` 中移除顶层静态 `import * as esbuild from 'esbuild'`，在 `bundlePlugin` 函数内部改为按需动态 `await import('esbuild')`，避免服务启动模块加载期对 esbuild 的同构锁定。
- **依赖分类校准**：将 `esbuild` 正式移入 `package.json` 的生产 `dependencies` 中，确保在任何分发环境下，通过管理后台在线上传安装第三方插件 ZIP 时均能顺利调用 esbuild 完成内存打包与沙箱编译。

### 3. CLI 生产环境守卫 (CLI Production Safeguard)
- 在 `cli.mjs` 中显式配置 `process.env.NODE_ENV = process.env.NODE_ENV || 'production'`，确保从命令行直接运行或通过 `npx` 唤起时，子进程默认进入高稳定性生产模式，安全提供 `dist/` 预编译静态资源与 SPA 路由。

## 版本说明

- 平台主包 `openlearn-next` 升至 **0.3.2**。
- 依赖审计：`dist/server.cjs` 外部依赖缺失项为 **0**，无多余未声明依赖。
- 全量自动化测试套件持续 100% 绿灯。
- 本补丁为无破坏性架构与打包优化，完全向下兼容所有业务数据与插件规范。

# Release Notes v0.7.9

**发布日期**: 2026-10-31

v0.7.9 完成课程包导入/导出闭环，并收敛作业命令归属。

## Features

- **课程包导出（Issue #363）**：新增 `GET /api/lessons/:id/export-package`，把课节正文、时间线、白板元素与 `/uploads` 附件打包为自包含 `openlearn.course-package` v1；附件以 base64 内嵌并替换为 `\${asset:<id>}\` 占位符。
- **导出权限与限额**：仅课程创建教师或管理员可导出；单包附件超 20MB 返回 `413 COURSE_PACKAGE_EXPORT_TOO_LARGE`。
- **导入侧占位符解析**：`lesson.content` 中的图片/文档占位符解析为真实 `/uploads` URL。
- **前端入口**：课程卡片与课节编辑器新增「导出为课程包」。

## Refactor / Performance

- **作业命令单一 owner**：`assignment.create/submit/grade` 只由 `assignment-eval` 注册；`ActionRegistry` 拒绝同 `commandType` 重复注册；插件停用时端点返回 `503 ASSIGNMENT_SERVICE_UNAVAILABLE`。

## Docs

- 新增《课程包规范》参考页；课程导入弹窗补充模板与限额说明。
- 文档站纳入 Sphinx 严格构建（`src/scripts/build-docs.sh`，`-W`）。

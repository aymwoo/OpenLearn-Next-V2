# Release Notes v0.4.0

**发布日期**: 2026年9月27日

OpenLearn V2 **v0.4.0** 是一个**课堂会话连续性与教学评测生态版本 (Session Continuity & Assessment Ecosystem Release)**。本版本实现了课堂会话的保存与恢复（教师离开后可随时回到当前状态）、首个教学评测类官方插件「题库与随堂测验」、通用考试课件得分采集链路的实测固化，并完成作业上传链路的系统性安全审计与修复。

---

## 一、课堂会话保存与恢复（Session Persistence & Resume）

教师离开课堂（刷新 / 断线 / 换设备 / 服务器重启）后重新进入，可**一键回到离开时的现场**：

- **课堂动态流落库**：新增 `classroom_feed` 表（`migrations/011`）与 `ClassroomFeedService`（`realtime-bridge` 同款事件订阅模式），随堂作答、签到、表彰、作业提交与批改、进度里程碑等课堂事件持久化为会话级事实，并向课节/班级房间广播 `classroom:feed_appended`。此前 `liveClassFeed` 是纯前端内存态（上限 50 条），离开即丢失。
- **恢复协议**：`GET /api/classroom/sessions/:lessonId` 扩展 `viewState`（当前白板页）与 `feedReplay`（最近 20 条动态升序回放），与既有 `stage / started_at / activePoll / activeBuzzer / activeCountdown` 一起构成完整恢复快照。
- **视图状态回写**：新增 `POST /api/classroom/sessions/:lessonId/view-state`，教师切白板页 / 切教学环节时防抖 500ms 回写；`currentPage` 存 `settings_json.viewState`，`activeSegmentId` 激活休眠列 `current_segment_id`。
- **「回到课堂」入口**：`ClassroomEntryPortal` 对存在进行中会话的课程显示绿色脉冲横幅，classId 从会话行带回（不依赖本地选择），一键直达恢复后的授课视图。
- **前端恢复逻辑**：动态流按 id 去重预填、环节与白板页一次性恢复（`initialPage` 只应用一次）、socket 实时增量追加。

## 二、题库与随堂测验官方插件（@teacher/plugin-exam-bank）

首个教学评测类官方插件，独立仓库 `openlearn-next/plugin-exam-bank`：

- **六类题型**：单选 / 多选 / 判断（API 建题自动补 正确/错误 选项）/ 填空（文本规范化自动判分）/ 量表（1-5，问卷专用）/ 简答（教师批阅）。
- **双形态**：随堂测验（实名）/ 问卷调查（匿名，`student_id = anon:<token>` 不入学生档案、统计不输出个人明细）；草稿 → 发布 → 关闭生命周期，迟交与空卷拦截。
- **实时推送答题**：发布经 SOCKET_ROUTES 推送到班级房间，学生端自动弹出答题界面（课中浮层槽位 `student.classroom.overlay`）；支持晚进/刷新恢复（`active_for_lesson` 脱敏查询）。
- **考试模式**：`config.examMode` 全屏深色接管（🔒 锁定标识 / 交卷前不可退出 / 三色倒计时归零自动交卷 / 迟到学生显示已结束不交空卷）。
- **统计聚合**：逐题正确率 / 选项分布 / 量表均值 / 填空高频答案 / 开放题答案列表 / 实名 roster 成绩明细；开放题批量批阅自动回算总分。
- **双通道架构**：REST（`ctx.http`，宿主网关 RBAC）与 Command（`invokeCommand`）共用 `core.ts` 同一组业务函数。

## 三、通用考试课件得分采集 E2E 固化

- 3 套**与平台零耦合**的通用考试课件 FIXTURE（`server/fixtures/demo-courseware/`）：仅依赖「任意 LMS 通用」的 postMessage 协议（`LMS_SUBMIT` / `LMS_FINISH` / `LMS_SAVE_PROGRESS`），验证平台通用采集能力而非定制课件。
- E2E 覆盖：三条得分通道的 status 映射、`aggregateAttemptScore` 四策略（LATEST/MAX/AVERAGE/FIRST）与满分归一化、promote → `assignment_submissions` → 学期成绩贯通。

## 四、作业上传链路安全审计（9 项发现全闭环）

- **H1 跨班越权（IDOR）**：新增 `assertClassMembership` 班级归属校验（详情/上传/提交/互评四端点），杜绝外班学生凭作业 ID 提交作业污染他班成绩册。
- **H2** 上传侧校验作业状态与截止时间；**M1** 50MB 同步写盘改异步；**M2** max_files 计数事务化消除 TOCTOU；**M3** 学生存储配额 200MB；**M4** 软删除文件物理 GC（7 天保留期 + 路径逃逸守卫）；**L1** `allowed_ext` 每作业扩展名限制（只可收紧全局白名单）；**L2** 上传策略单一事实来源 + 前后端同步守护测试；**L3** 写库失败回滚孤儿文件。

## 五、平台缺陷修复（本轮实测抓出）

- **插件 REST 网关 GET 通道不可用（V5.2 起即存在）**：`GET /api/plugins/:id(*)` 详情路由通配捕获子路径且注册在前，网关从未收到 GET 请求。修复为含子路径时 `next()` 放行；调用约定使用插件 DB UUID。
- **CSP `scriptSrc` 缺失 `blob:`**：插件前端以 Blob URL dynamic import 加载，CSP 拦截导致所有插件前端激活静默失败。补齐并注释来源。
- **`student.fullscreen` 考试模式槽位接线**：v5.1 声明后从未渲染的休眠槽位，挂载于 `StudentInteractiveOverlay`。
- **事件命名收敛**：socket 事件对齐「过去式」规范（`classroom:feed_appended`）；`ARCHIVED_REPORT_STAGE` 共享常量替代魔法字符串。

## 已知问题与观察项

- `writeLimiter`（60 写/分钟/IP）在课中高频场景偏紧，实测中偶发 429，建议后续按教室子网/角色放宽。
- 页面存在多条并行 socket 连接（StrictMode 双挂载 + 课节视图私有 `io()`），房间成员不一致；插件侧已自愈（专属 socket + join-room），架构收敛待后续版本。
- 宿主 EsmLoader 对 data: URL 热重载无法解析裸导入（`@openlearn/plugin-sdk`），插件更新后需重启服务器；更新失败自动回滚，数据无损。

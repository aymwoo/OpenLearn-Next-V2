# Release Notes v0.3.16

**发布日期**: 2026年9月18日

OpenLearn V2 **v0.3.16** 是一个重要的**核心运行时稳定性与前端模块加载补丁版本 (Runtime Stability & Frontend Loader Patch Release)**。本版本重点重构了前端插件模块动态转译器以支持现代 ESM 语法与 React 19 JSX 自动运行时，消除了 Worker 激活期异常引发的 60 秒假超时阻塞与看门狗误熔断，并彻底解决了 Worker 隔离模式下的数据库自动迁移权限拦截与异步 SQL 崩溃缺陷。

---

## 核心修复与运行时增强

### 1. 前端插件宿主模块转译与共享依赖扩充 (`FrontendPluginHost`)

* **全形态 ESM 裸模块动态转译器 (`transformBareModuleImports`)**：
  重构 `src/plugin-host/plugin-host.ts`，由原本单一正则替换升级为覆盖全语法的动态 Blob ESM 转译器：
  - 支持复合导入：如 `import React, { useState, useEffect } from "react"`；
  - 支持别名转换：如 `import { useState as useState2 }` 精确转译为对象解构 `{ useState: useState2 }`，避免浏览器原生解构报 `SyntaxError`；
  - 支持命名空间导入：`import * as React from "react"` 与默认导入；
  - 容忍多行换行与内联注释。
* **扩充共享依赖映射表 (`SHARED_MODULE_MAP`)**：
  将 `react-dom`、`react-dom/client`、`react/jsx-runtime` 正式纳入宿主共享依赖库白名单（由 4 个扩充至 6 个），并在 `src/main.tsx` 中向 `window.HostSharedDeps` 完整导出。
* **解决插件菜单与控制台挂载异常**：
  全面放行现代 `"jsx": "react-jsx"` 编译输出，彻底消除浏览器端 `TypeError: Failed to resolve module specifier "react"`，恢复恋云课程管理（`lianyun-course`）等插件在启用后的导航挂载（`teacher.tab`）与桌面仪表板部件（`teacher.dashboard.widget`）。

---

### 2. Worker 激活期快速失败与心跳续期机制 (`WorkerRuntime`)

* **5ms 激活期快速失败 (Fail-Fast)**：
  在 `WorkerManager.createWorker()` 中对底层 Worker 线程绑定激活期 `exit` 与 `error` 快速捕获通道。当插件在初始化/激活期间出现未捕获语法错误、模块缺失或进程暴毙时，主线程由原先盲目挂起 60 秒改为在 5ms 内立即拒绝并抛出精准的 `WorkerActivateError`，杜绝假超时现象。
* **WorkerInstance 细化生命周期 (`status: activating`)**：
  扩展 Worker 状态机引入 `'activating'` 阶段，仅在收到 Worker 线程的 `'activated'` 确认包后才提升为 `'running'`；当 Worker 在激活期意外退出时，仅做资源释放与状态标记，严禁触发 Watchdog 自动重启风暴，防御级联熔断。
* **沙箱全局未捕获异常陷阱 (`unhandledRejection` / `uncaughtException`)**：
  为 Worker 沙箱主函数注入全局异常拦截器，格式化错误堆栈并通过 IPC 通道向宿主发送结构化 `error` 事件后再优雅退出，杜绝未处理的 Promise Rejection 导致 Worker 无声崩溃。
* **插件上下文心跳 API (`ctx.reportProgress`)**：
  在 `PluginContext` 中暴露 `ctx.reportProgress(stage?, message?)` 标准心跳方法，支持耗时全栈插件在执行繁重大模型加载或复杂数据迁移时向宿主主动续期激活超时窗口。

---

### 3. Worker 数据库迁移白名单与异步 SQL 队列 (`ServiceHost` & `WorkerManager`)

* **`plugin_migrations` 表 DDL 白名单放行**：
  在 `ServiceHost.assertDatabaseAccessAllowed` 中将内部迁移表 `plugin_migrations` 加入 DDL 操作放行白名单，解决 Worker 插件调用 `ctx.db.migrate` 初始化版本表时因命名空间拦截触发 `WorkerCapabilityError` 的问题。
* **异步 SQL 队列与时序保证 (`pendingPromises`)**：
  在 Worker 沙箱的 `dbWrapper` 代理层引入异步 SQL 跟踪队列，在迁移函数执行完毕后通过 `Promise.all` 强制等待所有挂起的数据库查询与变更，确保即使插件代码未显式 `await` 内部 SQL 也能安全按序完成迁移后再更新元数据版本。
* **修复机房排座插件崩溃**：
  修复机房排座插件 `@aymwoo/plugin-lab-seat` 在 `activate()` 中异步 DDL 操作未捕获 Promise Rejection 导致的进程退出与看门狗重启循环。

# Release Notes v0.3.12

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.12** 带来了全新的**插件系统 HTTP Server-Sent Events (SSE) 流式传输与长连接安全防御体系（Plugin HTTP SSE Streaming & Safety Defense）**。本版本紧跟 v0.3.11 的 RESTful API 体系，进一步补齐了现代大模型交互与实时数据推送所需的低延迟流式通信能力，并在 Worker 沙箱隔离层与主线程网关之间打通了端到端流式 RPC 与反向算力熔断通道。

---

## 核心新特性与架构升级

### 1. 极简流式 API 契约 (`ctx.http.stream`)
* **统一流式路由注册**：
  在 `IPluginHttpRouter` 中新增流式注册方法，插件开发者可以在 `activate(ctx)` 生命周期中一键定义流式端点：
  ```typescript
  // 支持缺省方法（匹配 GET/POST）或显式指定动词
  ctx.http.stream('/chat', async (req, stream) => {
    stream.write({ type: 'start', model: 'gemini-3.0' });
    for (const chunk of textStream) {
      if (stream.isClosed) break; // 及时响应客户端断开
      stream.write(chunk);
    }
    stream.end();
  });
  ```
* **标准化事件流写入器 (`PluginStreamResponse`)**：
  提供 `stream.write(data, event?, id?)`、`stream.end()`、`stream.error(err)`、`stream.isClosed` 属性及 `stream.onClose(callback)` 监听器，自动格式化多行数据为符合 W3C 标准的 SSE 事件协议（`data: ...\n\n`）。

### 2. Worker 隔离模式跨线程流式 RPC 通道
* **逐 Chunk 毫秒级双向 IPC**：
  扩展 Worker 线程与主线程之间的流式协议族：`httpStreamStart`、`httpStreamChunk`、`httpStreamEnd`、`httpStreamError`、`httpStreamAbort`、`routesRegistered`。Worker 插件中写入的每个 Chunk 会在毫秒级内被流式封装并透传至主线程 Express 客户端响应。
* **路由元数据即时同步**：
  Worker 插件激活时会自动向宿主上报包含 `isStream` 标识的路由表，网关在接收到客户端 HTTP 请求时能毫秒级区分流式长连接与常规 RESTful 短请求。

### 3. 反向中止与大模型算力熔断保护 (T-STR-04)
* **用户主动取消与异常中断拦截**：
  当客户端断开连接（如用户在界面点击“停止生成”、刷新或关闭浏览器窗口）时，安全网关立即通过 `res.on('close')` 捕获断开事件，并通过 RPC 向 Worker 派发 `httpStreamAbort` 信号。
* **算力与 Token 零浪费**：
  Worker 内部立即将 `stream.isClosed` 标记为 `true` 并触发 `stream.onClose(cb)` 监听器，使插件能够立刻终止正在进行的大模型 API 调用或密集运算任务，彻底杜绝僵尸进程与无意义的 Token 消耗。

### 4. 纵深流式安全防御机制 (Threat Mitigations)
安全网关针对长连接潜在的攻击与资源滥用风险构建了 6 道流式防护网：
1. **并发长连接硬上限 (T-STR-01)**：单客户端 IP 最多维持 5 个并发流，单个插件最多 50 个并发流，超出硬阈值直接拦截并返回 `429 Too Many Requests`，有效免疫慢速长连接 Slowloris 攻击。
2. **三阶梯超时看门狗 (T-STR-02)**：
   - **首包看门狗 (10s)**：Worker 若未在 10 秒内写入首个 Chunk，强制切断并返回 504 超时；
   - **空闲看门狗 (60s)**：相邻 Chunk 写入间隔超 60 秒自动熔断清理；
   - **生命周期硬上限 (300s)**：单次流式长连接最长允许存活 5 分钟，防止长流无限占用 Socket。
3. **单 Chunk 体积硬限制 (T-STR-03)**：单个 SSE 数据块大小限制在 **64KB** 以内，超限立即抛出熔断错误，防御内存洪峰攻击与 OOM。
4. **SSE 响应标头强制清洗与固化 (T-STR-05)**：出站前强制固化注入 `Content-Type: text/event-stream; charset=utf-8`、`Cache-Control: no-cache, no-transform`、`Connection: keep-alive`、`X-Accel-Buffering: no` 等安全头，禁止插件篡改。
5. **生命周期全量资源回收 (T-STR-06)**：在插件卸载、热重载或宿主重置时，自动终止所有未关闭的流并向 Worker 广播 abort，无任何资源残留。

### 5. 开发者测试工具包赋能 (`@openlearn/plugin-test-kit`)
* 导出 `createMockStreamResponse()` 工具方法与 `MockStreamResult` 接口，插件开发者可在无网络服务器与真实浏览器的纯单元测试环境中，完整断言流式 Chunk 发送序列、错误抛出与连接断开模拟。

# Release Notes v0.3.22

**发布日期**: 2026年9月25日

OpenLearn V2 **v0.3.22** 是一个**互动课堂全面深化与安全收敛版本 (Interactive Classroom Deepening & Security Hardening Release)**。本版本补齐了课中互评、教学模式、作业中心等课堂核心环节的真实数据链路（消除 12 处伪数据来源），将课件成绩聚合与分数监视器从第三方插件收编为平台原生能力，上线插件中心社区市场与课件运行时脚本扩展点，并完成一轮覆盖 14 项问题的系统性安全审计（4 CRITICAL / 8 HIGH / 3 MEDIUM 全部修复）。

---

## 一、互动课堂：起始门户、教学模式与四页面扩展

### 1. 起始门户与教学模式体系

- **起始门户页** (`ClassroomEntryPortal.tsx`)：教师进入「互动课堂」先看到门户页 —— 遥测岛（时钟 / 网络时延 / 席位就绪率）、课程卡片马赛克、班级标签 + 32 席位矩阵、教学模式选择器、45 分钟节奏管道与课前自检体检卡。初始化失败不切换视图，避免「界面已进课堂但服务端无会话」的割裂状态。
- **教学模式后端**：迁移 `008_teaching_modes.sql` 新增 `teaching_modes` 表；`GET/POST/PUT/DELETE /api/classroom/teaching-modes`（读开放、写限管理员）；内置 5 种模式（讲授 / 探究 / 协作 / 体验 / 练习）以代码常量兜底，不写进迁移 seed。
- **网络时延探测**：新增 `GET /api/ping`（不鉴权、不访库）与 `useNetworkLatency` hook（模块级单例，多组件共用一轮询）。

### 2. 上课流程四页面扩展

全部挂在 `LiveClassroomView` 顶栏入口，支持中英双语与四套主题：

- **家校通知生成器**：AI 生成全班学情简报 + 逐生家长通知（≤ 80 字），AI 失败逐生回落模板，整体仍 200。
- **AI 实时学情预测**：一次 AI 调用批量预测全班 5 维掌握度 + 风险等级；AI 不可用时自动降级为启发式并标注「降级模式」。
- **课堂异常告警中心**：直接消费既有 `errorStore` 数据，双 Tab + 严重度筛选 + 一键复制学生 ID。
- **小组协作白板**：零依赖 SVG 画布（笔 / 矩形 / 圆形 / 橡皮 + 8 色 + 分组派位 + 导出 SVG），实时同步预留 `classroom.collab.canvas` 扩展点。

新增 4 个插件槽位：`classroom.notification.tabs` / `classroom.pacing.dashboard` / `classroom.diagnostic.feed` / `classroom.collab.canvas`。

### 3. 课中全班大屏互评后端补齐

- 迁移 `009_classroom_peer_review.sql`：新增互评任务、评语、微勋章、提名、弹幕、量规维度 5+1 张表。
- `server/routes/classroom-peer-review.ts` 6 端点：一键「1 生评 2 份」分层分配（不产生自评）、大屏全量数据展示、防代评提交、越界分数 400、徽章幂等、不能自提名、弹幕截断 120 字。
- **作品池口径**：`courseware_attempt` 无 `lesson_id`，优先收本教案内嵌课件作答（`scope='lesson'`），不足 2 份回退全班（`scope='class'`），两者皆无则 400，不伪造作品。

## 二、课堂数据真实化（消除 12 处伪数据来源）

- **新增共享派生层 `useClassroomLiveData.ts`**：把已有 props/state 统一派生为逐生指标、课堂亮点、环节节奏，**不新增网络请求**。核心原则：无数据 → `0 / undefined / []`，绝不给「看起来合理」的假值（17 例单测锁定）。
- **主要修复点**：参与度分数 `60` → 真实 `progress_percent`；雷达图 `?? 95/90/88/96/98` 硬编码兜底移除（缺失维度虚线灰化 +「暂无数据」）；排行榜假小组名与写死积分移除；互评秀场 mock 学生/作品/评分全部改为 props 驱动。
- **panoramic-report 逐生明细**：服务端聚合测验 / 投票 / 通票数据，并按花名册补齐未互动学生；`ClassroomBriefingView` 的伪计算公式全部替换为真实明细，无数据渲染「—」。

## 三、作业中心与课件成绩体系原生化

### 1. 作业中心（P0 地基 → P1 学生闭环 → P2 互评闭环）

- **数据模型**：迁移 `005_assignment_hub.sql` —— `plugin_assignments`（同时挂课时与班级）、`plugin_submission_versions`（不可变版本）、`plugin_assignment_files`、`plugin_peer_review_tasks`；重建 `plugin_submissions` 去掉单条唯一约束（重交不再丢档）。旧数据零丢失，迁移幂等。
- **权限修正（P0 阻塞缺陷）**：角色兜底新增 `assignment:read/submit/review/manage`，学生提交不再被 `CapabilityGuard` 拒绝；学生写权限收窄为处理器内所属权校验，无法冒充他人。
- **HTTP 端点**（`server/routes/assignment-hub.ts`）：作业 CRUD、原始二进制文件上传（扩展名白名单 + magic bytes + 容器头校验）、提交与版本管理、互评分配。
- **前端闭环**：`AssignmentSubmitDialog`（多选/拖拽上传、版本历史、失败重试）、`AssignmentBindingField`（教师绑定作业实体）、`AssignmentPeerReviewPanel`（双盲互评、四维量规、截止锁定）、`AssignmentPeerProgressPanel`（教师进度 + 异常标记）。

### 2. 课件成绩「按策略留分」原生化

- 迁移 `004_courseware_score_config.sql`：每课件可配置满分折算 / 权重 / 聚合策略（`LATEST` / `MAX` / `AVERAGE` / `FIRST`）。
- 新增纯函数模块 `packages/plugins/courseware-score.ts`，命令处理器与 HTTP 路由共用同一聚合口径；四个原生命令含 `courseware.regrade_attempts`（改策略后重算历史成绩，学生无需重做）。
- **分数变量监视器原生化**：从插件迁出为 `packages/plugins/score-monitor-script.ts`，由内置插件经扩展点注册；覆盖白板 `srcDoc` 路径（`/bridge.js?cw=`）。脚本字面量以断言测试守护，杜绝历史上「正则双重转义」「`</script>` 截断」两类事故复发。

### 3. 课件运行时脚本扩展点

- 新增内核服务 `CoursewareRuntimeScriptRegistry`（`@openlearn/plugin-sdk` 已导出 Token）：插件可向课件 iframe（opaque origin，服务端拼接 HTML 是唯一投递位置）注册 head / body-end 脚本，支持按课件精确匹配、优先级排序、热更新覆盖；无注册脚本时静默降级，既有渲染路径零影响。

### 4. 互动课件体验修复

- **成绩提交 500 修复**：actorId 归一化（裸 UUID → `user:<id>:<role>`）+ payload 空值裁剪；教师预览补 `student:write` 能力。
- **学生提交归属丢失修复**：新增 `POST /api/courseware/attempts/:attemptId/adopt` 认领无主 attempt（iframe 不带会话导致 `guest` 堆积、真实学生 403 的根因）。
- **结算页自动上报**：Bridge SDK 新增 `ResultWatcher`，命中「通关 / 结算 / 正确率」等强结束信号后从可见元素抓分（`X/Y` → 百分制），每次作答只上报一次。
- **成绩榜学生可见**：课件元素右上角「查看成绩」展示全班榜单，自己高亮 + 名次标注；占位 attempt 不计入，同分并列。
- **`/raw` 与 `/attempts` 越权修复**：补 `requireAuth` + 所属权校验；学生只拿榜单字段，原始作答与教师评语仅教师可见。

## 四、插件生态：社区市场与安全加固

### 1. 插件中心社区市场

- 服务端经 `PLUGIN_COMMUNITY_REGISTRY_URL` 代取注册表（前端无 CORS 负担），格式容错（v1 信封 / `items` 别名 / 裸数组），非法条目整条丢弃并计数。
- `POST /api/plugins/install-from-url`（管理员专属）服务端下载安装；失败回退浏览器直传 `upload-zip-raw`。
- 出站 SSRF 防护统一收敛至 `server/utils/url-safety.ts`；插件包下载限 60 秒 / 200MB。
- 新增 `PluginCommunityPanel`：预览卡片、搜索 / 标签筛选 / 排序、已安装与可更新标注（semver 校验双端版本）。

### 2. 安全修复

- **插件自建表 SQL 注入**：`ensureTable` / `table` / `dropAllTables` 的表名与列定义（来自 ZIP 上传，不可信输入）强制校验，阻断多语句注入；inline 与 Worker 双模式同等校验。
- **插件更新检测 Shell 命令注入**：`execSync(git ls-remote ...)` → `execFileSync` 参数数组执行；`updateSource.repo` 白名单校验（仅 `owner/name` 形式的 GitHub / Gitee）。
- **端点补鉴权**：`/api/plugins/market`、`check-update`、`execute-command`、`/api/lessons/:id/eval-submissions` 等补 `requireAuth()`。
- **诊断上报回退端点**：关闭无鉴权后门，防身份冒充（学生名取服务端权威值）、1 秒限频、payload 收敛截断。
- **AI Provider 密钥解密分叉**：新增 `packages/core/di/api-key-crypto.ts` 唯一事实来源，修复「测试按钮通过但插件 AI 调用 401」（PM2 下 `ENCRYPTION_KEY=''` 必现）；解密失败抛可操作错误而非发送密文。
- **插件卸载残留**：Worker 模式插件停用后命令 / 订阅 / 定时器 / 能力永久残留的问题修复，卸载流程无条件回收资源并撤销能力。

## 五、系统性安全审计（14 项）

覆盖 974 个源文件 / ~180K 行代码，**4 CRITICAL + 8 HIGH + 3 MEDIUM** 全部修复：

| 级别 | 修复项 |
|---|---|
| CRITICAL | `os.ts` 命令注入 RCE（`exec` → `execFile`）+ `/api/upload` 补鉴权 |
| CRITICAL | 16 个未认证端点加固（db-status / files / mfe / plugins / audit-report / commands / agent / activities） |
| HIGH | 明文密码回退移除、临时密码泄露、CORS null origin、点击劫持（`sameorigin`）、全局限流（写 60/min、AI 10/min）、作业提交 IDOR |
| MEDIUM | `/uploads` 静态资源认证、xlsx → exceljs（CVE 原型污染）、devDependencies 归类修正 |
| 加固 | vite build target `es2022`、tsconfig strict 子集启用、死 store 清理 |

完整报告：`docs/architecture/security-remediation-report.md`。

## 六、体验与工程化

- **Tailwind v4 迁移遗留修复**：语义色透明度写法（78 处静默失效）、默认边框色回落 `currentColor`（63 处「黑线」）、`dark:` 变体绑定 `data-theme`（156 处）、3 个从未定义的设计令牌补齐。类名与调用方零变更。
- **学生端异常遥测**：学生端报错经 Socket.IO 实时推送教师端（Toast + 红色角标 + 排查日志直达），持久化至 `events` 审计表；学生端浮窗改为左下角极简角标，降低课堂干扰。
- **高频轮询日志治理**：CommandBus 默认静默只读指令集合 + `DEBUG_COMMAND_BUS` 开关；白板课件拉取 30 秒缓存 + 防抖；消除终端刷屏与 2 秒轮询全树重渲染。
- **互动课堂字段名失配修复**：投票 / 节奏信号 / 结课通票三处前后端字段名不一致（投票全部落库 `"undefined"`、信号恒 400、通票反馈静默丢弃）全部修复，新增 11 例契约测试锁定。
- **文档漂移审计流水线**：`audit-tools/` 三脚本 + CI `docs-drift-audit` job + 本地 pre-commit 钩子；当前基线 `docs facts: 103 / code facts: 55 / drift items: 0`。README 重写为面向外部读者的平台能力总览，新增 classroom / interaction / resource 三篇运行时架构文档。

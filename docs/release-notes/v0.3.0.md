# Release Notes v0.3.0

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.0** 是平台进入全新演进阶段的里程碑大版本。本版本全面落地了面向现代智慧课堂的 **现代教育 OS 主题系统（Theming System Engine）**、解决了长久困扰系统演进的 **数据库版本化迁移体系（Database Migration Pipeline）**，并实现了 **5.4 倍单测并发提速与多项架构级质量基准清障**。

---

## 核心亮点 (Key Highlights)

### 1. 现代教育 OS 主题系统 (Theming System Engine)
- **多维度原生语义化设计 Token**：
  - 基于 Tailwind CSS v4 构建全局语义 Token 层，统一规范 `--bg-app`、`--bg-surface`、`--bg-surface-secondary`、`--border-theme`、`--text-main`、`--color-primary` 等变量。
- **4 套教育场景预设**：
  - **浅色日间 (Light)**：自然采光与日常白日教学；
  - **暗夜极客 (Dark)**：微机房、编程机考与夜间专注备课；
  - **教学护眼防眩光 (EyeCare)**：针对教室大屏高亮投影定制的淡雅薄荷绿底衬；
  - **经典墨绿黑板 (Chalkboard)**：复现传统物理黑板与粉笔质感。
- **白板渲染引擎主题深度联动**：
  - 白板底色、极坐标点阵与笔刷/文字对比度自适应反转（Dark/Chalkboard 模式下黑色笔迹自动映射为粉笔白 `#f8fafc`）。
  - 白板悬浮工具栏、分页导航胶囊、大纲抽屉无缝换肤。
- **主题可视化设计器 (`ThemeDesignerModal.tsx`)**：
  - 支持 4 套创意预设（高雅墨蓝、暮樱柔粉、复古秋叶、深海极客）。
  - 核心色盘与设计 Token 实时自由调节。
  - 拟真沙箱实时微缩预览，直观呈现看板、指标卡、操作按钮与白板卡片。
  - 支持配置 JSON 导入、导出、剪贴板复制及 `localStorage` 持久化存储。
- **微前端沙箱与互动课件主题同步 (MFE & Courseware Theme Bridge)**：
  - 宿主与课件 iframe 跨域广播 `theme:changed` 与 `LMS_THEME_CHANGED` 消息。
  - Bridge SDK 内部自动响应式注入 CSS 变量与 `data-theme` 属性。
  - 为课件与微前端提供 `window.LMS.getTheme()` 运行时查询 API。
  - 课件 iframe `onLoad` 主动握手同步，彻底杜绝首屏样式闪烁。

---

### 2. 数据库版本化迁移体系 (Database Migration Engine)
- **迁移加载与执行引擎**：
  - 研发 `server/utils/migrate.ts`，支持扫描 `migrations/*.sql`，支持 `-- UP` 与 `-- DOWN` 分隔符语法。
- **幂等防护与版本追踪**：
  - 服务启动时自动执行迁移并记录状态至 `_migrations` 表（包含 `applied_at` 与 `checksum`），具备天然幂等性与 duplicate column 容错保护。
- **首批核心迁移入库**：
  - 规范并落地 `000_initial_schema.sql`、`001_add_execution_mode.sql`、`002_add_client_session_expiry.sql`、`003_classroom_runtime.sql`，消除了历史遗留的僵尸迁移隐患。

---

### 3. 架构健壮度与质量工程飞跃 (Engineering Excellence)
- **5.4 倍测试并发提速**：
  - 在 `process.env.VITEST` 下实现按 Worker Pool ID 分配独立临时 SQLite 数据库，彻底消除并发测试写入死锁。
  - `vitest.config.ts` 开启 `fileParallelism: true`，全量 175 个测试文件、982 个用例运行耗时由 204 秒极限缩减至 **38 秒**！
- **Worker 插件自建表 DDL 白名单修复**：
  - 修复 `ServiceHost` 支持 `dbPluginId` 与 `manifestId` 双重命名空间校验，解决插件建表误判为越权 DDL 的问题。
- **React 19 Rules of Hooks 违规清零**：
  - 清理 `PluginCardRenderer` 与 `ActivityWorkspaceWidget` 中的条件 Hook 调用，保证 React 19 Fiber 调度安全性。
- **ESLint 静态质量门禁 0 Error**：
  - 规范 `eslint.config.js`，达成代码静态分析零报错。

---

## 升级与兼容性说明 (Upgrade & Compatibility)

- **主包版本**: `openlearn-next` 升级为 **0.3.0**。
- **数据库**: 系统启动时将自动检测并同步执行 `migrations/` 下尚未应用的 SQL 迁移文件，无需手动执行数据库脚本。
- **课件兼容性**: 既有 interactive courseware 无需修改代码，引入最新 Bridge SDK 即可自动感知宿主主题换肤。
- **全量测试基准**: 175 个测试套件，982 个用例 100% 绿灯。

# Release Notes v0.3.4

**发布日期**: 2026年9月6日

OpenLearn V2 **v0.3.4** 是针对平台内核跨模块版本声明一致性的**架构对齐补丁**。本版本系统性排查并消除了核心运行时、Bootstrap 启动流水线、服务注册中心与管理接口中分散硬编码的旧版本字符串，确立了平台核心版本单一真理源（Single Source of Truth）。

---

## 主要更新

### 1. 核心单一版本真理源设立
- **集中收敛**：新建 `packages/core/version.ts` 模块，集中导出 `PLATFORM_VERSION` 与 `OPENLEARN_VERSION` 常量；
- **全生命周期引用**：PluginHost 宿主管理器、Bootstrap 平台构建器、DI 统一服务注册表全面切换为此单一来源，杜绝各子模块因硬编码字面量产生的版本脱节。

### 2. 运行时与服务探针版本获取加固
- **端点解耦**：重构 `server.ts` 中的 `/health` 探针接口，直接引用 `PLATFORM_VERSION`；
- **消除执行路径依赖**：彻底解决了通过 `npx` 或跨任意工作目录执行时，因 `process.cwd()` 缺少 `package.json` 而退回默认旧版本的隐患。

---

## 版本说明

- 平台主包 `openlearn-next` 升至 **0.3.4**。
- 为后续 0.3.x 迭代奠定了版本一致性基础设施。

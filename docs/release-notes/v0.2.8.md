# Release Notes v0.2.8

**发布日期**: 2026年9月4日

## 主要更新

### 1. 第三方插件白板扩展能力（Plugin Whiteboard Extensibility）
- **自定义全屏渲染器**：插件在 `activate(ctx)` 内调用 `ctx.ui.registerFullscreenRenderer(type, renderer)`，为自定义白板元素类型注册全屏视图；`unregisterFullscreenRenderer(type)` 注销。
- **自定义属性编辑器**：插件调用 `ctx.ui.registerPropertyEditor(type, editor)`，在白板右侧属性面板渲染插件定制的编辑器。
- **所有权感知的注册表**：`fullscreenRendererRegistry` / `propertyEditorRegistry` 增加 `unregister` / `unregisterPlugin`，记录注册方 `pluginId`；插件停用、卸载或激活失败时宿主自动清理其注册，且插件无法越权清除宿主内置渲染器或其他插件的注册。
- **SDK 类型导出**：`@openlearn/plugin-sdk` 新增 `FullscreenRendererProps` / `FullscreenRenderer` / `PropertyEditorProps` / `PropertyEditorComponent` 四个 type-only 类型。

### 2. 扩展点组件统一注入课堂上下文（Unified Classroom Context）
- `ExtensionPointRenderer` 向所有扩展点组件 props 统一注入 `{ lessonId, classId }`（当前课程/班级，`string | null`），合并优先级最低、可被 `slotProps` 覆盖；`teacher.tab` 面板形态同步注入。
- `FrontendPluginContext` 新增 `ctx.context.get()` / `ctx.context.subscribe()` 只读快照与订阅，供事件回调、命令处理等非渲染场景读取当前课程/班级。
- 字段契约：`lessonId` 源 `appStore.selectedLesson`；`classId` 源 `appStore.liveClassSelectedClassId`。

### 3. 文档修正
- 更新 `docs/reference/plugin-ui-extension-slots.md`：明确各槽位注入的 `slotProps` 字段与合并顺序，补充 `ctx.context` 用法，纠正「插件可直接 `import { fullscreenRendererRegistry } from '@/...'`」的误区（`@/` 为宿主内部别名，第三方插件打包不可解析）。

### 4. Worker 插件数据库安全屏障
- `ServiceHost` 拦截 IDatabase RPC，禁止 Worker 插件访问核心安全表（`users` / `client_sessions` / `plugins` / `ai_providers` 等），并将 DDL 操作限制在插件自身命名空间（`plugin_<id>_` 前缀）内。

## 版本说明

- 平台 `openlearn-next` 升至 **0.2.8**。
- `@openlearn/plugin-sdk` 保持 `3.5.0`（新增类型随下一版 SDK 发布）。
- 相关测试：`src/plugin-host`（12 文件 / 111 用例）、`src/features/whiteboard`、`src/components`、`packages/plugin-sdk` 全部通过。

# System Configuration 系统配置规范

本页汇总平台全部服务端配置入口：环境变量、SQLite 数据库路径、会话密钥与插件 `manifest.configuration`。**当前唯一真源是代码**（`server.ts`、`cli.mjs`、`packages/core/worker-runtime/worker-manager.ts`、`packages/core/worker-runtime/plugin-quota.ts`、`packages/core/db/retention-policy.ts`），本页与其同步于 v0.7.4。

> **本页是全平台唯一的环境变量清单。** 其他文档（含[系统配置架构规范](../architecture/configuration.md)）只描述设计形态与约束，不再并列维护第二份变量表——两份清单必然分叉。清单完整性由 `audit-tools/envcheck.py` 守：代码读取、`.env.example`、本页表格三方比对，任一侧缺失即报 drift。

## 3. 会话与密钥

- 会话采用 **HttpOnly Cookie**（`server/middleware/auth.ts` 的 `getCookieToken`），无独立 JWT 签名密钥环境变量；登录态由服务端 sessions 存储校验。
- 唯一的加密密钥是 `ENCRYPTION_KEY`（AES-256-GCM）。它加密 AI Provider API Key，也加密 `classes.class_passcode`。未设置环境变量时，钥匙在数据目录的 `storage/encryption-key`（与 `bootstrap-credentials.txt` 同目录，权限 600）。启动日志和管理后台会警告这是自动生成的钥匙，应改设 `ENCRYPTION_KEY` 并离线备份该文件。`site-backup` 不打包这个文件。环境变量若与文件不一致，进程报错并说明如何二选一，不会悄悄换钥匙，也不会再使用只活在内存里的临时密钥。

## 4. 插件 `manifest.configuration`

插件在 manifest 中声明配置 schema（[plugin-manifest-spec §2.5](../plugin/plugin-manifest-spec.md)），由 `IConfigService`（`ctx.config`）提供读取与变更订阅：

- 属性类型：`string | number | boolean | integer`，支持 `default` / `enum` / `minimum` / `maximum` / `description` / `scope`（共 7 个字段）；
- `scope` 决定该键允许在哪一层被覆盖（`platform` / `school` / `class`），缺省只有平台层；解析顺序为 **班级 > 学校 > 平台 > manifest 默认值**；
- 值存放在 `plugin_config` 表（迁移 `037_plugin_config_scopes.sql`），不再写入 `plugin_storage`（该位置仅作旧库回退）；
- `ctx.config.onChange(callback)` 全键订阅，回调签名 `(key, newValue, oldValue)`，**不带作用域参数**，需要区分来源时自行记录。

> ⚠️ **`showInDashboard` 不是框架识别的保留键。** 插件卡片上的「总览」开关对**所有**插件都存在，状态保存在浏览器 `localStorage`（`openlearn:dashboardVisibility`，见 `src/plugin-host/plugin-host-store.ts`），与插件配置无关。在 manifest 里声明 `showInDashboard` 只会得到一个普通配置项，既不影响开关可用性，也不影响小部件显隐。

完整的声明字段、存储结构、校验与失败语义、REST 入口见[系统配置架构规范 §2](../architecture/configuration.md#2-插件级配置三级作用域)。

## 5. 启动期环境变量强校验（P1）

`server/security/env-validation.ts` 的 `assertStartupEnv()` 在 `startServer()` 最早期执行，在接触数据库与插件运行时之前拦截配置笔误。规则分两档：

- **error（拒绝启动）**：`PORT` 越界/非整数、`TRUST_PROXY` 无法识别的取值、`ENCRYPTION_KEY` 非法、`OPENLEARN_WORKER_ISOLATE` / `OPENLEARN_PLUGIN_PERMISSION` / `OPENLEARN_WORKER_LIVENESS` / `BRIDGE_HOOK_TELEMETRY` / `OPENLEARN_PLUGIN_QUOTA` 拼写错误、`OPENLEARN_PLUGIN_MAX_RSS_MB` / `OPENLEARN_PLUGIN_CPU_QUOTA_MS` / `OPENLEARN_PLUGIN_CPU_WINDOW_MS` / `OPENLEARN_WORKER_LIVENESS_INTERVAL_MS` / `OPENLEARN_WORKER_LIVENESS_GRACE_MS` 带单位、负数或低于下限、`ALLOWED_ORIGINS` 非法 origin、`OPENLEARN_SEED_PASSWORD_MODE` 不是 `default` / `random`。
- **warning（仅告警）**：生产环境未显式设置 `ENCRYPTION_KEY`、`TRUST_PROXY=1/true` 且可能被公网直连、`ALLOWED_ORIGINS` 含 `*`、`METRICS_TOKEN` 过短、iframe/LTI 白名单无法解析、生产环境把 `OPENLEARN_ADMIN_PASSWORD` / `OPENLEARN_TEACHER_PASSWORD` 设为用户名（初始口令本来就是用户名，这里只提醒「确认已改密」，不阻断启动）。

校验是纯函数，便于单测覆盖；副作用（打印与抛错）集中在 `assertStartupEnv()`，由 `server.ts` 统一处理退出。

# 课程编辑页统一与学案编辑器增强

> 状态：已实施（P0 / P1 / P2 完成，门禁验证中）
> 日期：2026-11-22
> 范围：教师端课程编辑入口、学案活动/首页块编辑、试题（引用试卷）、HTML 课件、插件活动类型扩展

## Context

教师端目前从「课程管理」打开课程时，`onViewCourse` 固定进入 `lesson_editor`；学案课程只有在环节类型为 `xuean` 且 Mode Pack 开启时才会间接落到学案编辑器，无环节或环节类型缺失时会错误进入白板。同时学案编辑器仍是 P0 形态：活动类型无法引用试卷、HTML 课件需要手填 UUID/JSON、首页块是纯 JSON 文本框、活动/块不能拖拽排序，也没有插件扩展点。

本次目标：**一个课程编辑入口，按课程类型/当前环节自动进入白板或学案编辑器**；学案编辑器支持引用试卷作为试题活动、可视化选择/上传 HTML 课件、可视化编辑首页块、拖拽排序、预览与错误态，并允许第三方插件声明新的活动类型与编辑器/学生端渲染。

## 阶段划分

### P0 统一课程编辑入口

**目标**：点击课程即进入正确编辑器；混排课程在同一壳内按环节切换。

1. 新增 `src/features/classroom/mode-pack/resolvePrepFace.ts`
   - `resolvePrepFace({ activeSegmentType, lessonModePackId, lessonDeliveryMode, requestedTab })`
   - 优先级：当前环节类型 → 课时模式包/交付模式 → 请求的 tab。
   - 复用 `resolveModePackForSegment`、`normalizeSegmentType`、`resolveLessonModePackDeliveryMode`。
2. `src/hooks/useAppComposer.ts` 的 `onViewCourse`
   - 根据课时 `mode_pack_id` / `delivery_mode` 选择 `teacherTab`（`xuean` → `xuean_editor`，其余 → `lesson_editor`），再 `setSelectedLesson`。
3. `src/features/teacher/TeacherView.tsx`
   - 把当前 `teacherTab` 作为 `requestedTab` 传给 `ModePackPrepShell`。
4. `src/features/classroom/mode-pack/ModePackPrepShell.tsx`
   - 无 `activeSegment` 时改用 `resolvePrepFace` 的课时模式结果，不再默认白板。
   - 保留环节条与 `data-*` 测试标记。
5. 测试：`resolvePrepFace` 三路优先级；`ModePackPrepShell` 无环节的学案课；`useAppComposer` 入口路由。

**验收**：学案课（含无环节）进入学案编辑器；白板课行为不变；混排课通过环节条切换。

### P1 学案编辑器核心增强

#### 1. 试题：引用现有试卷

**数据约定**（沿用现有 `quiz` 活动类型，避免新增白名单）：

```json
// lesson_activities.config_json
{ "assessmentId": "...", "classId": "...", "assignmentId": "...", "title": "..." }
```

**服务端**（`server/routes/lesson-activities.ts`）

- 新增 `POST /api/lessons/:lessonId/activities/assessment`
  - 入参：`{ assessmentId, classId, title?, required?, visible?, activityId? }`
  - 权限：`authorizeLessonStaff` + `authorizeClass(..., 'staff')` + 试卷归属校验。
  - 校验 `classId` 属于该课时关联班级（复用 `class-access.ts` 的 `lessonLinkedClassIds`，需导出）。
  - 事务内：
    1. 查找同 `assessment_id + class_id + lesson_id` 的 open assignment；
    2. 不存在则调用 `AssessmentService.publish` 创建（**不要在前端直接调 publish**，它非幂等）；
    3. 新建/更新活动，写入类型化 config。
  - 返回 `{ success, activity, assignment, reused }`。
- 新增 `GET /api/lessons/:lessonId/linked-classes`（class-staff）：返回 `{ id, name }`，供班级选择器。
- 活动列表/导出保持原样，不裁剪 `config_json` 未知字段。

**前端**

- 新增 `XueanAssessmentActivityEditor.tsx`：选择试卷（`assessmentApi.list()`）、班级、标题与必做/可见；保存走新原子接口。
- `XueanActivitiesPanel.tsx`：类型选择中 `quiz` 显示为「试题（引用试卷）」，选中后渲染该编辑器；已有活动可重新绑定。
- 新增 `AssessmentActivityCard.tsx`（学生端）：
  - 读取活动 config；
  - 「开始/继续作答」→ `assessmentApi.startAttempt(assignmentId)`；
  - 内嵌 `AssessmentRunner`；
  - 提交后 `postActivityProgress(activityId, { status: 'submitted', progressPercent: 100 })`，并调用 `attemptResult` 展示分数。
- `StudentXueanView.tsx` 在活动列表中按类型分发到 `AssessmentActivityCard`。

**测试**

- 服务端：assignment 复用/新建、非本班 403、无题目 400、非试卷 owner 403、旧活动更新。
- 前端：选择器保存、学生开始/提交/结果三态。

#### 2. HTML 课件可视化选择

- 新增 `src/features/xuean/CoursewarePicker.tsx`（或 `features/courseware/`）：
  - `GET /api/courseware` 列表 + 搜索；
  - 上传：`POST /api/courseware/upload`（base64Data）→ `POST /api/courseware/confirm`；
  - 返回 `{ coursewareUuid, title }`。
- `XueanBlocksEditor.tsx`：
  - `interactive_courseware` 改为选择器，不再要求手填 JSON；
  - 保留「高级 JSON」折叠入口；
  - 保存后仍由服务端 `syncBlockSurface` 生成 `html_courseware` Surface。
- `XueanActivitiesPanel.tsx` 的 Surface 绑定区：`html_courseware + courseware` 时使用同一个选择器替换 UUID 输入。

**验收**：教师可从列表选择或上传新课件，插入首页块/活动；学生端 `LearningSurfaceHost` 正常渲染。

#### 3. 体验优化

- **拖拽排序**
  - 活动：复用现有 `reorderLessonActivities`，前端增加拖拽手柄（保留上下移按钮）。
  - 首页块：新增 `POST /api/lessons/:lessonId/blocks/reorder` 与 `reorderLessonBlocks`，镜像活动重排。
- **可视化编辑替代 JSON**
  - `learning_goals / key_points / resources / operation_tips / works_showcase / reflection` 改为逐条输入（增删行），内部仍序列化为 JSON 数组。
  - `free_html` 增加安全预览；保留原始文本编辑。
- **预览与错误态**
  - 面板加载/保存失败显示明确错误与重试；空态提供「新增」引导。
  - 活动卡片支持「预览此活动」，复用 `StudentXueanView` 或按类型渲染只读预览。

### P2 第三方插件活动类型扩展

**新增 manifest 贡献与槽位**

- `contributes['xuean.activity.type']`：
  ```json
  {
    "id": "ext-lab:experiment",
    "type": "ext-lab:experiment",
    "labelZh": "虚拟实验",
    "labelEn": "Virtual Lab",
    "icon": "FlaskConical"
  }
  ```
- 前端槽位：`xuean.activity.editor`、`xuean.activity.student`（`slotProps` 含 `activity/config/lessonId/studentId/lang/onChange`）。
- 规则：`type` 必须为 `<manifest.id>:<name>`，长度 ≤ 96，字符集 `[a-z0-9_.-]`。

**服务端**

- 新增 `server/services/xuean-activity-types.ts`：
  - 从 `pluginLifecycleManager.listPlugins()` 读取 active 插件 manifest，收集 `xuean.activity.type`；
  - 导出 `isAllowedXueanActivityType(type)`（内置 ∪ 插件），供 `lesson-activities.ts` 校验；
  - 未知/未安装/非法命名空间一律拒绝（400）。
- 导入学案包时：插件类型缺失则保留原 type（只读降级），不静默丢弃。

**前端**

- `XueanActivitiesPanel`：把 `pluginHost.getExtensions('xuean.activity.type')` 合并进类型选项。
- 选中插件类型时渲染 `ExtensionPointRenderer slot="xuean.activity.editor"`；学生端 `ActivityItem` 渲染 `xuean.activity.student`，缺贡献时显示「插件未提供编辑器」错误态。
- `manifest-schema.ts` 的 `frontendSlotsShape`、`src/plugin-host/types.ts` 的 `ExtensionSlot` 增加三个槽位；同步更新 `docs/reference/plugin-ui-extension-slots.md`。

**测试**

- manifest 校验/命名空间；服务端接受已安装插件类型、拒绝未安装类型；前端选项合并与缺省回退。

## 关键边界与风险

- **publish 非幂等**：所有发布必须经新的原子活动接口，事务内复用 open assignment；前端不得直接调用 `assessmentApi.publish`。
- **lesson→class**：`classId` 不信任前端，必须校验属于该课时关联班级；导出并复用 `lessonLinkedClassIds`。
- **插件类型安全**：命名空间 + 字符集 + 长度；服务端只校验不执行；插件停用后旧活动降级只读。
- **混排/无环节**：优先级固定为「环节 → 课时模式 → 请求 tab」；旧学案数据不迁移。
- **权限**：活动 CRUD 需 lesson staff；试卷需 owner/管理员；班级需 staff。
- **兼容**：`config_json` 与 `content_json` 保留未知字段；导入导出不裁剪。
